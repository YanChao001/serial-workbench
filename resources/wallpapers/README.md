# 内置图片壁纸

此目录保存随软件发布的 JPEG/PNG/WebP 原件，与[矢量皮肤](../skins/README.md)和用户图库分开。

1. 图片可放子目录，扩展名支持小写或全大写；先离线优化，构建保持原始字节与分辨率。
2. 按相对路径字符排序，可用 `001-名称.jpg`。展示名去掉数字前缀和扩展名，默认背景由 Rust 定义为纯色。
3. [manifest.json](./manifest.json) 必须恰好覆盖全部图片，每张登记唯一稳定 ASCII ID，仅含字母、数字和 `._:-`，最长 128 字符。

[bundled-wallpapers.ts](../../src/lib/bundled-wallpapers.ts) 通过 Vite glob 收录，桌面与网页使用内容哈希 URL。设置仅存 `{ "kind": "bundled", "id": "bundled:001" }`，改名/替图时保留 ID；删除 ID 后不再解析，不兼容旧文件名身份。

缩略图使用平滑预览，窗口加载原图，图片位于皮肤网格前并共用背景透明度。新增资源核对来源许可、默认背景、缩略图和明暗效果。
