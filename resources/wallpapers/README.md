# 内置图片壁纸

此目录保存随软件发布的图片原件，与[矢量皮肤](../skins/README.md)及用户导入的“我的壁纸”图库分开维护。

## 新增与排序

1. 将 JPEG、PNG 或 WebP 图片放入本目录，可使用子目录；支持 `.jpg`、`.jpeg`、`.png`、`.webp` 及其全大写扩展名。图片应先离线优化，构建保留原始分辨率与文件字节。
2. 推荐使用 `001-名称.jpg`、`002-名称.webp` 等文件名排序。应用按相对路径的字符顺序排列，显示名称会去掉数字排序前缀与扩展名；首张图片是首次使用和恢复默认设置时的默认壁纸。目录没有图片时使用纯色。
3. 正常运行开发或构建命令即可，无需注册清单或修改源码。增删文件后，已运行的开发服务器可能需要重启；正式构建会重新收录当前全部图片。

[资源清单](../../src/lib/bundled-wallpapers.ts)通过 Vite glob 导入图片，桌面和网页构建均自动生成带内容哈希的资源地址，支持网页子路径部署。安装版与便携版通过前端资源携带图片。

## 设置与维护

设置保存稳定 ID `bundled:相对文件名`。替换同名文件可以更新图片而保留选择；改名会改变身份，删除或改名后的旧选择回落到当前默认壁纸。

内置图片排在设置页皮肤网格的前面，共用背景透明度；用户可切换纯色、矢量皮肤或自己的图片。缩略图与用户图库复用平滑采样的预览组件，窗口背景加载完整原图。内置图片通过本目录维护，用户图库单独保存导入的图片。

新增图片时核对来源和使用授权，并检查构建后的默认背景、缩略图及明暗主题效果。
