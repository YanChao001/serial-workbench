# 产品需求

面向嵌入式调试、工业通信和设备测试，建设 Windows/macOS/Linux 桌面串口工作台。基座承担设备、原始流与任务，内置和市场 Node 插件使用统一 SDK；人工、CLI、MCP 和后续浏览器共用同一业务定义。

本文定义目标，当前实现与验证看[进度](./progress.md)，阶段安排看[规划](./plan.md)。需求包含 218 个原编号、28 项补充及 LAN-01，共 247 条；别名共享实现但保留 ID。原始 HTML 来源 SHA-256：decb7085efbed8e9443d794dff658999a884f1b29f250caf8ae761d82ddd606b。

## 全局要求

- 桌面、CLI、MCP 同时提供纳入的业务、设置、工作区和插件管理能力，发现、动作和结果使用同一目录与授权。客户端适配器只处理传输、呈现和系统交互。
- AI 操作携带 GUI 定位并展示输入、过程与结果；保护人工草稿，暂停跟随只停导航，人工接管与业务取消分别处理。并发活动可追溯，不建立内部 LLM/自有云产品。
- 默认跟随选定 AI 会话并绑定观看窗口，查询也携带 revealTarget；同任务轮询更新所属面板，并发按开始顺序定位，晚结果回到原活动。人工接管先停止该 AI 对目标的新修改及排队写入，结算在途工作后交还控制；恢复观看与重新授权分别执行。无头运行保留活动，后续 GUI 可恢复查看。
- RX 保留原始接收字节；TX 保留变换后字节、已接纳范围与真实回执，partial/unknown 不推断成功，也不静默重发。
- Host 为唯一设备持有者，关闭视图不停止录制或后台任务；视图冻结、客户端断开、合作取消和 Host 退出分别结算。
- 统一可信 Node，代码执行信任与设备/任务/文件 API 授权分开。首次审阅来源及范围，同源相容升级保留信任；导入、生成或打开项目不自动执行自由脚本。
- 插件后台不依赖视图，重计算与脚本进入可终止 worker/子进程；Web UI 不直接访问 Node/Tauri。整套包预构建平台依赖，用户设备不执行 npm 安装脚本。
- 首批浏览器作为本机 Host 客户端，使用受保护配对和同源入口；零安装 Web Serial 另列后续。桌面文件选择/剪贴板等由明确客户端能力承接，无客户端时报告不可执行。
- LAN 两端分别绑定 Host 身份，B 唯一持口并仲裁，A 使用带源端命名空间的会话。断网、撤销和交互租约失效不伪造 B 已接纳任务停止；远端原始文件路径不成为跨机权限。
- 工作区与设置保留 CAS、原子提交和未来格式保护，加载配置不自动连接、发送或运行脚本。恢复另存或归档原件，旧软件 API/格式/插件不兼容、不迁入。
- 常用能力安装后可用，专业功能按同一 Node 契约扩展；公开 SDK 由参考实现、失败场景和跨入口行为验证后冻结。
- MCP 适配器独立于插件宿主，插件故障后仍可查询、停止和管理；目录变更通知与重新连接均可发现新工具。图表/选区导出提供离屏入口，不依赖打开的插件页面。

## 归属与阶段

基座负责资源所有权、流、任务、接口、共享状态、基本 Text/HEX、工作区和通用安全；内置 Node 提供终端、协议、图表、自动化、网络和诊断；市场 Node 扩展专业工具/设备/分析。跨层协作不重复持有资源，归属不改变需求范围。

各行阶段表示交付切片，完整阶段定义见[规划](./plan.md#阶段路线)。范围排除和后续项继续保留 ID 与依据，状态只在[账本](./feature-status.json)维护。

## 本轮范围决定

- 桌面全面串口助手与外部 MCP；不做移动端、自建云平台或内置 LLM。FUT-01/02/03 经外部 AI 和 MCP 实现，FUT-04 提供接口。
- 浏览器本轮连接独立 Host，作为共享 GUI 客户端；原零安装 Web Serial 保留后续专项。桌面和浏览器共享会话、权限、插件贡献和实时状态。
- 每次 AI 功能调用使绑定的观看窗口自动跳到对应页、会话、面板；轮询更新同一任务，其他窗口同步业务状态。暂停跟随只停止导航，人工接管暂停该 AI 的新修改并结算在途任务，草稿独立保留。
- 每个基座或插件业务功能同时登记动作、查询、状态和 GUI 定位，向 GUI/CLI/MCP 开放；设置、工作区与插件管理也覆盖。各条目验收同时核对人工操作和 MCP 调用，不保留仅有界面可操作的业务功能。
- 共享可信 Node，内置/市场共用 SDK，沿用一次信任和会话/任务 scope。Node 有 OS 权限，进程隔离不是强沙箱；SEC-03 据此改写。M0 完全删除旧插件 runtime、SDK、协议及全部配套资产；旧软件接口和数据格式不兼容，合理职责按新合同复用。
- JS/TS 为内置首选，Lua/Python 可选外部运行时插件；LAN 共享/接管、用户自配数据库/网关保留，不扩成产品云账号业务。
- Node 后台与浏览器可执行的 UI 分入口，使用同一消息契约；关闭视图后业务继续。窗口、剪贴板等操作定位客户端，业务与文件导出可无头执行。读写授权和任意代码执行/插件管理授权分开。
- 原始 RX 保留接收字节，原始 TX 保留全部发送变换后的字节及实际接受范围；输入草稿和变换记录作为元数据。断网、租约和去重遵循[契约](./contracts/README.md)，发行版本切换遵循[架构](./architecture.md#更新与分发)。

## 新增用户场景：局域网端口共享

| ID     | 功能与要点                                                                                                                                   | 产品归属                             | 阶段                                        | 验收重点或范围                                                                          |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ | ------------------------------------------- | --------------------------------------------------------------------------------------- |
| LAN-01 | **两台电脑间像本地一样使用共享串口**<br>B 运行本软件并共享选定串口，A 经 LAN 配对后使用；参数、收发、协议、图表、录制和 MCP 均走相同工作流。 | 基座为主；内置 Node 消费同一会话合同 | M2 闭环→M3 契约冻结→M4 内置体验→M6 跨机验收 | B 唯一持口并统一 TX 仲裁，A 通过 Remote Peer 使用同一会话；首次信任后普通操作直接执行。 |

LAN-01 通过标准：

1. B 选择共享端口并展示范围；A 经发现/地址连接，首次配对绑定 Host 身份、加密链路与授权，后续识别同一对端。
2. A 远端 ID 带 B Host 命名空间；参数/控制线/错误计数按 B 实际能力显示，真实变更结果同步所有客户端。
3. B 持唯一原生句柄；A/B 桌面、浏览器、CLI/MCP 和插件支持路径共享会话及 TX 仲裁；多读者、控制权与独占传输任务分开，不能交错破坏帧。
4. 同一完整录制样本和解析配置经本地/LAN 产生相同字段/图表；A 可用命令、脚本、协议、图表和录制。时序敏感任务固定在 B；跨机文件用引用传递，capture 保留来源、方向、序号与源端时间。
5. MCP 操作远端会话后 A 的观看窗口自动定位；B 及其他客户端同步状态，B 可自行跟随。请求身份转发至 B，重连查同一 operation；重复/冲突 ID、部分写入和崩溃未知结果分别测试。
6. A Host 失联后交互控制租约到期，B 取消该流程未执行写入；B 已接受的独立任务继续，A 重连取结果。覆盖分段/慢连接、缓存缺口、B 拔插重启；恢复不误连、不重放旧 TX。
7. B 可看配对客户端、控制权和任务；共享范围由 B 校验。撤销/接管停止远端发起任务并按取消点结算，本地任务继续；代码执行和插件管理另有授权，日常获准动作不重复弹窗。
8. M6 用两台真实电脑的三平台代表组合、IPv4/IPv6 和实际 USB 转串口/回环对端验证，记录设备驱动、RTT、时钟偏移估计误差、一致性和恢复结果；含协议版本不匹配及后台升级。
