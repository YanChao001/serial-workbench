# 开发规范

本文维护实现约束；操作步骤见[开发指南](./development.md)，验证选择见[测试](./testing.md)。新增规则应对应具体故障或维护成本，同一规则在此维护一次。

## 模块与类型

- 按职责复用现有实现，不合理接口与状态模型直接重设计。删除能力时清理入口、命令、权限、依赖、SDK、桥接、资源、专属测试和失效指南。旧软件 API、存档和插件不兼容、不迁入。
- 页面局部状态放在组件；公共偏好使用现有 Provider、模型和同步器。业务数据由所属服务写入，跨域通过有语义的公开接口访问；共享工具不反向依赖业务页面。
- 手写 TypeScript 用 `unknown` 收窄未知输入，使用字面量联合，禁止 `any` / `enum`。边界做运行时校验，内部依赖已建立的不变量。
- Rust DTO 是公共契约来源，手写前端不复制 wire 模型。Host 类型使用 contracts 包，Native 命令通过 `src/lib/tauri.ts`；签名、DTO、注册改变后生成并提交结果。
- 错误按稳定 `code` 分支，内部细节写脱敏日志。Operation 接纳、完成、取消等待和实际停止分别表达，不把 queued 当保存成功。
- 异步工作处理卸载、StrictMode、晚到结果、切换目标和旧代次；清理取消等待与资源回收责任分别明确。存储保持原子写入、revision 冲突及未来格式保护。

## 代码组织

TypeScript 文件、组件文件和目录用 kebab-case，组件与类型用 PascalCase，Hook 用 `useXxx` / `use-*.ts`；Rust 模块用 snake_case，真常量用 UPPER_SNAKE_CASE。内部处理器用 `handleXxx`，回调 prop 用 `onXxx`。持久字段与外部 API 沿用契约命名。

模块内部使用相对导入，前端跨目录优先 `@/`；沿用文件已有分组。新代码先组织数据流和命名，再提取复用；只为实际调用方设计公开入口，不引入空壳层、无约束透传或“通用”配置。

Rust 命令处理边界适配，服务持有业务规则，`lib.rs` 负责组装。使用结构化错误、显式所有权和 RAII；阻塞系统工作进入有界执行器，任务持有实际资源直到完成，避免阻塞异步运行线程。

注释解释原因、契约和反直觉行为。自有解释性注释用中文，工程脚本帮助与结果用英文；保留技术标识、上游许可及生成格式。`src/components/ui/` 维持调用兼容并保留本地修复，`src/styles/shadcn.css` 保持上游原文；生成文件通过脚本更新。

## 界面

- 复用 AppShell、HashRouter、路由元数据和 commands；新增导航、命令及快捷键同时核对真实入口。工作台采用顶部连接、中央独立滚动接收和底部常显发送，辅助工具按需展开。
- 使用语义 token 和共享控件。普通面板用 panel，输入用 control，浮层用 popover，长文本用 reading，关键错误用 solid，图片/图表用 artwork；布局分组 transparent。保留文字与背景配对，避免重复叠加 blur。
- 尺寸与布局刻度以现有 CSS、设置模型和窗口配置为准，不在文档复制常量。响应式以容器可用宽度为准，窄窗口及最宽侧栏组合下主要操作仍可达。
- 维护焦点、键盘、IME、语义名称和错误反馈。输入框有 label，图标按钮有可访问名称及 Tooltip；装饰图标隐藏于辅助技术。弹层关闭后返回合理焦点，禁用原因就近说明。
- 选中、悬停、焦点和错误可辨；方向、状态和多序列内容结合文字或结构表达。检查明暗、透明壁纸、高对比和减少动效。
- 文案同步 `src/i18n/zh-CN.ts` / `en.ts` 及功能词典；提示写明问题和用户可采取的动作。技术细节进入日志或详情，常用界面不堆积内部身份和诊断字段。
- 持续动效复用 [useMotionActivity](../src/hooks/use-motion-activity.ts)，结合应用/系统偏好、可见性与离屏状态暂停；连续运动提供暂停入口，卸载释放计时器、观察器、事件和捕获，减少动效时提供静态结果。装饰不增加业务轮询。
- 标题栏空白拖拽区与按钮分开；macOS 保留系统窗口按钮。侧栏调宽同时支持指针和键盘，取消回退，折叠保留名称、选中态与提示。
- 皮肤、壁纸和品牌修改源资源后运行对应生成或检查，核对来源许可、缩略图与实际窗口；具体入口见[资源说明](../resources/skins/README.md)。

根页面保持稳定滚动槽，工作台接收区与侧栏独立滚动；切换路径重置主内容滚动，同页设置定位保留上下文。页面边界保留外壳和恢复入口，请求错误由所属数据区处理。

相关字段使用 fieldset/legend，各输入保留 label；placeholder 只提供示例。设置搜索复用索引和稳定控件 ID，保留输入焦点与 IME，选择后定位实际控件。保存状态复用 [SettingsPersistence](../src/components/settings-persistence.tsx)：自动保存成功保持安静，失败保留输入并提供重试，加载/保存结果向辅助技术宣告。空、加载、失败和长文状态保持相邻操作及滚动稳定。

HTTP(S) 外链复用 [ExternalLink](../src/components/external-link.tsx)，保留标准链接语义、键盘/中键和失败反馈。代码展示复用 [CodeBlock](../src/components/code-block.tsx)，未知语言按 text；高亮限额不截断原文，保留选择/复制及 Markdown 局部焦点与滚动。正文对比度按 4.5:1 验收，内容专用配色同时核对明暗与强制颜色。

## 安全

Rust 提交边界验证身份、目标、内容格式、权限及资源预算；生成类型只提供编译期约束。文件引用、导出路径、外链与媒体读取按实际能力授权，不把任意路径或 Shell 执行交给前端。

- 检查路径组件、链接、特殊文件与替换竞态；使用真实文件身份和打开后的校验，字符串前缀不足以建立目录边界。
- 读取和写入均复核资源权限，派生结果保留来源；撤权后停止继续交付内容，错误不得泄露私有路径或正文。
- 原生工作及输出分配受名额和字节预算约束，取消或票据释放不提前归还实际工作持有的预算。系统进程用参数数组，不拼接用户文本。
- 保存、导入、重置和恢复保留原件及失败证据；未来格式拒绝覆盖。清理源码或生成物不清除用户目录。
- CSP 来源按实际用途最小放行，capability 按窗口和命令维护。Markdown 跳过原始 HTML 并过滤危险协议；深链只导航允许页面，不授予设备或文件权限。
- 图片按实际内容完整解码并限制像素/边长；媒体票据 URL 不携带 Host 凭据或真实路径，释放票据不绕过读取时的权限复核。测试 WebDriver 只在测试 feature/配置启用，正式包不开放测试服务。
- 私钥、令牌和口令使用受控渠道及系统存储；`VITE_` 仅放公开配置。真实 .env、Secrets 和用户数据不进入源码、日志或聊天；泄露后撤销或轮换。
- 日志记录稳定 code 和必要上下文，避免令牌、请求正文及可避免的用户路径；反馈前复核脱敏结果。漏洞按 [SECURITY.md](../SECURITY.md) 私密报告。
- 新依赖说明用途、来源、许可、平台和包体影响，审查安装/构建脚本并提交锁文件。Actions 固定完整 SHA；依赖更新集中评审，审计入口见[测试](./testing.md#依赖审计)。

## 协作

`main` 是唯一长期分支，短期分支使用 `feature/`、`fix/`、`docs/`、`chore/` 和简短名称。所有分支保持线性，同步只用 fast-forward / rebase，经 PR squash merge 合回。

同一可验收里程碑的实现、测试、审阅修正和文档集中为一个提交。提交与 PR 使用 Conventional Commits，类型/模块保留英文，主题和正文用中文。PR 说明最终行为、原因、验证及相关未测范围。

跨域归属、公共契约、权限、生命周期、数据恢复或发布变化，实施前说明影响、实际替代方案和验收；普通局部改动直接实现。长期设计理由更新[架构](./architecture.md#关键取舍)。

同一工作区约定文件范围，共享入口、清单、锁和生成物串行维护；共用 target 的 Rust 与生成任务顺序执行。保留用户未提交修改。

本地 main 仅 fast-forward。独占的已推送分支需要改写时，先 fetch、核对包含远端提交并固定完整 SHA，推送用指定 ref 和预期 SHA 的 `--force-with-lease`；远端改变即停止核对。共享分支先协调，main 禁止强推。合入后确认主线包含完整交付，再删除已用本地/远端分支与 worktree。

`marketplace/` 是独立 Git 子模块，分别管理 PR；市场合入并推送后，主库引用实际远端提交。配置、密钥和工作流恢复按各自范围验收。

## 文档

文档采用中文、UTF-8 和相对链接，英文 README 保留独立入口。README、CONTRIBUTING 和 AGENTS 提供导航；规则、步骤、需求、计划和结果分别放到所属文档。

核对事实时区分预期要求、当前实现与已验证范围；发现差异记录问题，不改写需求掩盖缺陷。版本、命令、DTO 与预算优先链接配置和生成来源。示例注明工作目录、shell、前置条件与完整参数。

移动或删除文档同步本地路径、标题锚点、代码中的固定路径及状态账本引用。保留需求 ID、有效契约、安全边界、许可证和第三方归属。

删去重复过程、工具指令、对话背景和泛化提醒；限制写成影响操作的具体条件、后果或下一步。当前任务更新进度，单次完整日志和截图留在 PR/CI artifact，不堆入长期指南。
