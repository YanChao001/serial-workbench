# 界面规范

界面复用语义 token 和现有组件，保持绘制、交互与阅读体验一致。验证按 [日常验证范围](../testing.md#日常验证范围) 选择。

## 设计基础

- 组件与基础样式由 [components.json](../../components.json)、[index.css](../../src/index.css) 组织；`styles/shadcn.css` 保留上游原文，升级见文件头。
- 颜色、字体、圆角与尺寸消费 CSS 变量和 Tailwind 刻度；平台窗口控件的固定尺寸集中在外壳。
- `next-themes` 使用 `.dark` class；组件保留用户配色，内置背景消费皮肤环境色，用户照片保留原色。
- 页面表面与外壳布局分别由 [app-surfaces.css](../../src/styles/app-surfaces.css)、[app-navigation.css](../../src/styles/app-navigation.css) 维护；动画遵循 [动效](#动效)。

## 公共控件外观

普通控件、分组和阅读区复用应用的字体、尺寸、材质及交互状态；页面负责业务布局、内容密度与专用绘制。

[surface-tokens.css](../../src/styles/surface-tokens.css) 维护材质参数，[control-styles.css](../../src/styles/control-styles.css) 维护通用绘制规则。共同样式修改放在这两处，新增共享文件接入现有装配与检查。

游戏、图表或专用操作区可采用独立视觉设计，在模块说明中写明范围，并保留可读性、键盘操作、主题与减少动效支持。

共同样式变更按影响检查控件的主题、外观参数、交互状态和窗口场景；[无头界面检查](../testing.md#浏览器生产构建冒烟) 覆盖当前真实页面。

## 外观设置

外观由 `<html>` 的 data 属性驱动，普通组件只消费语义 token。取值、默认值与迁移以 [设置模型](../../src/lib/settings-model.ts) 为准。

| 属性                                            | 作用                                       |
| ----------------------------------------------- | ------------------------------------------ |
| `data-accent`                                   | 强调色，覆盖主色、焦点环、图表和侧栏强调色 |
| `data-radius`                                   | 圆角，改写 `--radius`                      |
| `data-font` / `data-font-size`                  | 字体和根字号                               |
| `data-background` / `data-background-intensity` | 窗口插画、用户图片及装饰强度               |
| `data-motion`                                   | 全局动画与过渡策略                         |

主题在挂载前恢复首屏偏好，运行时由 `ThemeEffects` 与 `use-theme-switch` 提交。主窗口与次窗口共用设置同步入口，沿用 [架构说明](../architecture.md) 的 revision 与缓存约定；过渡见 [动效](#动效)。

**加一个外观项的顺序**：`lib/settings-model.ts` 加类型、默认值与归一化 →
`applySettings` 写 data 属性 → `index.css` 写对应规则 → 设置页加控件。
改变持久化格式时同步处理迁移；设置页复用现有设置来源，局部预览调色板留在所属组件的 token 内。

主题色由 [accent-colors.ts](../../src/lib/accent-colors.ts) 注册，色块和主题共用配色变量。自定义色在弹层中编辑草稿，确认后一次提交，取消保留原配色；切换预设保留上次自定义原色。设置保存归一化的不透明 RGB 十六进制值，明暗变体由共同规则生成，渐变和色相记忆留在取色控件内。

背景在 `lib/backgrounds.ts` 注册，由 `window-background.tsx` 装配、`skin-artwork.tsx` 加载 [皮肤 SVG](../../resources/skins/README.md)。新增时同步映射、风格标识与中英文文案，画廊从注册表生成；展示名称与持久化 ID 分离。纯色模式隐藏装饰并禁用强度控制。图片导入保留成功项与失败明细，晚到结果按当前选择处理，取消背景保留收藏；存储见 [数据存储](../architecture.md#数据存储)，取舍见 [ADR 0004](../adr/0004-wallpaper-library.md)。

背景透明度档位与默认值以 [backgrounds.ts](../../src/lib/backgrounds.ts) 为准。0% 隐藏皮肤并恢复实体表面，100% 完整显示壁纸，同时保留正文、导航和控件的阅读保护；材质曲线在共同来源维护。纯色、高对比度和缺少模糊能力时使用实体降级。滑条支持拖动、方向键和 Home / End，显示当前百分比、等距刻度与“不透明 / 透明”端点。

窗口尺寸由原生几何状态维护。预设来自应用配置，标明逻辑像素宽高，选择后立即应用并记忆；工作区不足时适配并提示，其他无效预设禁用并说明原因。界面显示实际尺寸，失败保留状态与重试入口；浏览器禁用原生尺寸操作并说明限制。

启动位置提供“记住上次位置”和“居中”，默认值见设置模型；保存后在下次创建窗口时生效，已有窗口保持原位。恢复默认设置的确认框说明窗口尺寸和位置策略的恢复范围，保存失败时保留确认框和错误。

## 主题插画与轻量资源

内置皮肤使用透明线条蒙版，由 `styles/window-skins.css` 按当前主题和强调色着色；绘制与资源约束见 [皮肤资源说明](../../resources/skins/README.md)。

- 背景覆盖标题栏、侧栏和主体，表面材质按强度调节，正文、控件、弹层和关键错误保持清晰。
- 缩略预览和实际背景复用同一绘制源与居中裁剪方式。
- 装饰层使用本地资源，保持指针穿透并从无障碍阅读顺序中隐藏。
- 明暗主题和强调色共用语义 token；高对比度与强制颜色模式优先恢复实体 surface，移除装饰。
- 内置全窗口装饰保持静态，视频壁纸静音循环，沿用活动状态暂停和封面降级；播放与清理遵循 [动效](#动效)。

## 标题栏

“视图 → 全屏沉浸”、命令面板和 F11 共用命令。进入真实全屏后隐藏标题栏和侧栏；边缘唤出面板覆盖正文并使用阅读材质，保留滚动位置，焦点、菜单或侧栏调宽期间保持展开。边缘入口兼容键盘与触屏，减少动效时立即切换。全屏切换自动将导航焦点交给正文时不显示正文焦点环；用户用 Tab 进入正文时保留可见焦点与键盘滚动。F11、Esc 和退出按钮恢复布局与侧栏偏好，Esc 优先关闭菜单。原生通过门面、浏览器通过 Fullscreen API 读取实际状态，系统拒绝或外部退出时同步界面。

- 高度 40px（`h-10`），自绘：左侧共用 SVG 图标与菜单，右侧命令搜索、主题切换与窗口按钮。语言在设置中选择；系统窗口标题及图标保留无障碍名称。
- 拖拽区域用 `data-tauri-drag-region`，只加在空白容器上；按钮与菜单不要加。
- 窗口按钮只在 Tauri 原生窗口显示；网页共用应用标题栏与页面布局。
- 浏览器窄屏在同一标题栏内显示页面选择器并收起桌面菜单，选择器复用 `APP_ROUTES`，切换同一组真实页面。原生能力的环境限制在对应页面说明。
- macOS 保留系统红绿灯（`tauri.macos.conf.json`），标题栏左侧留 `pl-[78px]` 并隐藏自绘按钮。
- 平台判断统一走 `lib/platform.ts`。

菜单按已实现的桌面功能组织，当前保留文件、视图和帮助。直接导航使用页面名称；执行前还需输入或确认的操作使用省略号。菜单、命令面板和快捷键复用同一命令入口。

## 颜色与材质

| Token                                            | 用在哪                               |
| ------------------------------------------------ | ------------------------------------ |
| `bg-background` / `text-foreground`              | 页面底色与主文字                     |
| `Card` / `.app-surface` / `text-card-foreground` | 随皮肤强度变化的普通卡片与手写面板   |
| `--surface-card-muted`                           | 随皮肤强度变化的次级面板与卡片页脚   |
| `--surface-reading`                              | 代码、日志、诊断与吸顶表头的阅读材质 |
| `--control-background`                           | 输入、次级按钮与一般状态的控件材质   |
| `--surface-state-hover` / `selected`             | 普通交互的悬停与选中底色             |
| `text-muted-foreground`                          | 次要文字，材质中消费受保护的前景色   |
| `bg-primary` / `text-primary-foreground`         | 主按钮、强调元素                     |
| `bg-destructive`                                 | 删除、不可逆操作                     |
| `text-destructive-foreground`                    | 实心警示背景上的文字或图标           |
| `border` / `border-sidebar-border`               | 分隔线                               |
| `bg-sidebar` / `text-sidebar-foreground`         | 侧边栏                               |

```tsx
// 材质与文字随主题和皮肤设置变化
<div className="app-surface text-muted-foreground border" />
```

主体阅读遮罩独立绘制在 `.window-reading-surface`，与滚动主体分离，保持局部背景模糊的合成结果。遮罩和主体共用 `--app-content-inset`；侧栏折叠、展开和调宽时同步几何位置与过渡，拖动和减少动效模式保持即时更新。

React / Radix 入口通过 `data-slot`、语义角色和稳定的 `ui-*` 类接入共同绘制，普通 HTML 元素也有默认规则；布局 utility 与作者 CSS 保留定制优先级，适用范围见 [共同外观](#公共控件外观)。

| `data-surface` | 用途                                          | 绘制规则                                              |
| -------------- | --------------------------------------------- | ----------------------------------------------------- |
| `transparent`  | 布局、同一阅读面板内部的分组、嵌套代码        | 无底色或模糊，文字由上层阅读面保护                    |
| `panel`        | 普通含文卡片、手写业务面板                    | `--surface-card`，保留最低阅读底色，不加整块模糊      |
| `control`      | 输入、次级按钮、kbd、一般输出 / 会话状态      | `--control-background` 与局部模糊                     |
| `popover`      | 菜单、选择列表、搜索结果、通知                | 覆盖阅读材质与局部模糊；对话框使用专用 dialog token   |
| `reading`      | 长代码、日志、诊断、复杂输出、吸顶表头        | 更强的 `--surface-reading` 与语法色，防止滚动正文叠字 |
| `solid`        | 关键错误、恢复失败、平台原生选项              | 稳定实体底色，使用配对的前景色                        |
| `artwork`      | 图片、视频、Canvas / SVG 内容、作品或品牌场景 | 内容专用配色；外部工具栏和说明仍消费上述材质          |

共享 `Card` 与 `.app-surface` 对应 panel，`.app-control-surface`、`.app-overlay-surface`、`.app-reading-surface` 分别对应 control、popover、reading。手写容器声明用途；嵌套在 reading 中的 `CodeBlock` 可用 `data-surface="transparent"` 避免重复叠层。主按钮、勾选、开关、进度和滑块保留实体语义状态。

模态面板与遮罩共用材质参数，页脚和内部列表继承外层材质；主要磨砂由面板承担。原生 `dialog::backdrop` 与宿主遮罩共用规则；已有 `data-slot` 的浮层按其分类绘制，例如具有 dialog 语义的 Popover 仍采用 popover 材质。

输入和普通控件使用 `--input`，容器与分隔线使用 `--border`，卡片与浮层保持单层轻描边；强边界用于焦点、错误和选中状态。折叠区外框与标题共用 `--disclosure-radius`，展开时标题保留顶部圆角。

危险操作按钮和徽标使用共享的轻染底色、危险文字色及悬停 / 聚焦反馈；关键错误按自身语义使用实体表面。

placeholder 与弱说明使用 `--glass-muted-foreground`，链接使用可读前景色，hover / selected 复用共同规则；选中态保留边框或勾选等结构标记。短暂锁定的字段保持文字和底色稳定。新增控件或 slot 接入共同规则，或声明继承 / 内容专用角色；覆盖见 [样式检查](../../scripts/ui-style-policy.test.mjs)。

材质变化检查高透明度、深浅壁纸下的最终可读性。模糊用于局部表面，避免给整页叠加重复背景效果。

图表、插画和第三方组件的专用颜色集中在所属 token 或绘制规则，检查适用主题与强调色；普通业务界面继续使用语义 token。

多序列图形使用适配明暗主题的局部调色板，曲线与图例共用取色入口，并以名称或序号区分序列。

## 布局常量

标题栏与侧栏使用视口固定定位，根页面不滚动；`main` 和侧栏导航独立滚动，侧栏首尾操作保持可见。两侧共用稳定滚动槽，显隐、菜单和页面切换保持内容宽度与背景构图。外壳祖先保持固定定位的视口包含块，桌面与网页均按标题栏实际高度留出内容空间。

主导航页面直接从搜索、工具栏或功能内容开始，页面名称保留为 `sr-only` 标题。设置入口由路由的 `navigationPlacement` 标记，固定在侧栏左下角，只显示齿轮图标并保留名称、Tooltip 和选中态。命令搜索使用标题栏或快捷键入口。

滚动、惯性和边界反馈使用浏览器 / WebView 原生行为。主内容和侧栏共用 `.app-scroll-region` 管理滚动链与减少动效，具体手感由系统、设备和运行时决定。

切换页面路径时重置内容区滚动，保留导航焦点与侧栏位置；同页查询参数变化保留设置定位。滚动行为变化时检查长短页面，设备手感在相应设备上验收。

| 区域         | 值                                 | 类名                         |
| ------------ | ---------------------------------- | ---------------------------- |
| 标题栏高度   | 40px                               | `h-10`                       |
| 侧边栏宽度   | 默认 224px，180–360px；折叠 48px   | `settings-model.ts` 统一定义 |
| 内容最大宽度 | 1180px                             | `app-page-content`           |
| 内容区内边距 | 顶部 16px，横向 20–24px，底部 24px | `styles/app-navigation.css`  |
| 卡片之间     | 12px                               | `gap-3`                      |
| 页面区块之间 | 通常 16px，组内 8–12px             | 页面布局与所属组件样式       |

窗口默认最小尺寸见 [tauri.conf.json](../../src-tauri/tauri.conf.json)；工作区不足时，原生几何适配会临时降低约束。页面在默认最小尺寸下检查，并确保更小工作区中的主要操作仍可通过滚动到达。

侧栏支持指针和键盘调宽；拖动只预览本窗布局，释放或失去捕获后提交，取消则回退；键盘按操作提交。分隔条保留焦点、范围和值语义，双击或 Enter 恢复默认宽度。折叠导航保留名称与 Tooltip，展开时被截断的名称也提供全文提示；仅响应当前项悬停或聚焦，一次一条，布局变化后不残留延迟提示或旧退出动画。宽度与折叠状态复用设置模型持久化。

导航从 `routes.tsx` 派生，只显示非空分组。首组标题与折叠按钮共用顶部稳定行；折叠态保留展开按钮、分组语义和页面提示，底部提供命令面板及平台快捷键。页面呈现主标题，外壳保留轻量上下文。

响应式布局按可用容器宽度换行；检查最小窗口与最宽侧栏组合下的主要操作。

## 命令、搜索与恢复

菜单、命令面板和快捷键共用 `src/commands/` 与 `CommandsProvider`，路由命令从 `routes.tsx` 派生。新增共用操作先注册命令，入口复用显示名、快捷键格式和图标；图标作为装饰隐藏于辅助技术。键盘操作沿用匹配器对输入、IME、重复按键和冲突的处理。

设置搜索复用 `commands/settings-search.ts` 的索引和稳定控件 ID，结果显示在锚定输入框的非模态浮层，保留输入焦点与 IME。选中后清空查询、关闭浮层并定位目标；改控件 ID 时同步索引，检查中英文搜索与焦点。

设置保存的加载、失败与重试复用 [SettingsPersistence](../../src/components/settings-persistence.tsx)，反馈位置见 [说明与布局稳定](#说明与布局稳定)。未来 schema 保留可见拒写说明；浏览器中的原生入口说明能力限制，实际调用由门面检查。

设置分组以 [设置页](../../src/pages/settings.tsx) 为准，折叠内容支持搜索定位。同级字段复用 `SettingLabel` / `SettingRow` 的默认字号与对齐方式，小号文字用于辅助说明；同类图标共用尺寸和语义颜色。

问号帮助只补充影响操作选择且标签、选项尚未表达的信息，例如数据范围、权限、恢复规则和非显见的键盘操作。普通开关和按钮不再复述用途，确认框已有的说明不另设问号；禁用原因仅在对应限制存在时提供。已通过开关、选中状态、窗口变化或确认框关闭表达成功的操作保持安静，复制、导出等结果不直接可见的操作仍可反馈。

路由渲染失败由局部边界保留外壳与恢复入口，外壳或根 Provider 失败由最外层边界兜底；事件和请求错误由调用方处理，页面数据错误留在所属数据区。

## 字号层级

下表以默认根字号为基准，实际尺寸随外观设置缩放；布局变化时检查大字号下的可读性与溢出。

| 层级       | 字号    | 类名                            |
| ---------- | ------- | ------------------------------- |
| 页面大标题 | 24px    | `text-2xl`                      |
| 区块标题   | 16px    | `text-base`                     |
| 卡片标题   | 14px    | `text-sm font-medium`           |
| 正文       | 14px    | `text-sm`                       |
| 辅助说明   | 12px    | `text-xs text-muted-foreground` |
| 代码       | 12–13px | `font-mono text-xs`             |

页面以标题、正文、辅助说明组织层级，正文、关键导航与刻度在实际字号下保持可读。

普通状态、错误说明与操作反馈继承应用字体；等宽字体用于代码、表达式和按列阅读的原始数据。

## 组件选择顺序

先查找 `src/components/ui/` 和已有项目组件，能表达当前语义时直接复用或组合。缺少组件时可用 `pnpm dlx shadcn@latest add <name>` 引入上游控件，或在 `src/components/<domain>/` 自建；继续复用 token、键盘规则和焦点管理，依赖取舍见 [开发指南](../development.md#新增依赖的评审标准)。

有共同目的的设置、字段或操作参数使用 `fieldset`，以首个直接子元素 `legend` 提供组标题。内边距和标题字号由共同样式维护；组内间距与复杂工具条放在内容容器中，保留各字段的 label、禁用条件和搜索定位 ID。

相邻独立设置项使用 `.settings-list` 管理分隔线和留白；同一设置的标签、选项和状态保持在一个内容块内。

独立分组用 `data-surface="panel"` 保留阅读保护，面板内分组保持透明；正文、日志、列表和画布使用各自语义结构。容器统一管理间距，保留控件点击范围、长文和画布空间；缩略图按容器增减列数并保留名称与操作。

文本多行编辑统一复用 `ui/textarea`，与 `ui/input` 共用焦点、禁用及 `aria-invalid` 反馈；普通复选框复用 `ui/checkbox`，保留部分选择语义。原生日期、媒体与范围控件通过根 `color-scheme` 和强调色配合明暗主题。

单选下拉框复用 `ui/select`，普通下拉使用 `SelectContent position="popper"`。标题栏悬停说明复用 `ui/tooltip`，从按钮下方弹出，并保留按钮的 `aria-label`；Tooltip 本体与箭头共用阅读材质，箭头单次填色。

同排的单行输入、下拉框和按钮使用相同尺寸档位；默认与紧凑尺寸由共同样式维护，按外框和中心线对齐。触发项、展开选项和输入共用字号与行高 token，Portal 与隔离文档也遵循同一规则。

桌面普通区域使用实际业务菜单，文本输入、只读文本、可编辑区域和文本选区使用 WebView 原生编辑菜单，保留复制、粘贴、撤销和密码框限制。普通空白区屏蔽默认菜单；浏览器预览沿用网页默认行为。

## 说明与布局稳定

确认弹窗说明操作对象、数据范围和后果，各信息说明一次，诊断字段放入可展开详情。操作后保留列表和滚动位置，焦点回到原操作区域。

标题、控件名称和分组表达用途，页面介绍放在主标题下。补充说明仅保留影响判断的信息，长文和多步说明可展开；帮助入口支持悬停、键盘焦点与可访问名称，业务正文、首次使用信息和恢复入口持续可达。

按钮与菜单使用明确动作词，同一操作在各页面中保持一致；上下文已有对象时可写“安装”“更新”“新窗口”。中英文同步精简，保留授权、费用、联网、数据覆盖 / 删除、未保存工作与恢复条件；可访问名称保留区分对象的信息。

默认文案说明任务、结果和数据范围；框架、源码、协议与诊断放入可展开技术资料。主要操作保持可见并统一位置，低频管理放入具名菜单；不可恢复的删除、清空使用危险操作样式并确认。

收纳说明时移除空容器、固定高度和余留间距，帮助入口紧邻标题或控件。区块间距由外层管理，不叠加同层 gap 与 `space-y-*`。卡片按容器宽度分列、同排操作对齐；同组按钮同尺寸并允许换行；页签按完整项换行或滚动，标签内部不拆字。

路由加载使用 `page-loading.tsx` 的骨架、边距与稳定滚动槽。

placeholder 提供示例、格式或搜索方向，聚焦时保留、输入后自然消失；Label、可访问名称和持续限制独立提供。授权、不可恢复操作、未保存工作、首次阻断错误和字段校验保留可见说明，进一步解释再展开。

操作反馈使用右下角 toast；自动保存成功保持安静，保存失败保留修改并提供重试，恢复后撤回提示，切页保持单一反馈。加载与保存状态向辅助技术宣告。持续恢复的错误显示在原加载 / 数据区，字段错误就近关联；反馈保持相邻控件位置稳定。

持续状态、进度和摘要复用稳定行，长结果使用合理大小的阅读区；省略的文件名、来源和诊断通过键盘可达的详情、Tooltip 或复制提供全文。按改动检查空、加载、成功、失败及长文 / 窄屏 / 大字号，保持当前焦点和相邻控件稳定；用户主动展开、编辑和导航可改变布局。

处理溢出时调整容器和换行，保持正文可达、字号可读。

## 异步数据区的状态

| 状态 | 要求                                                     |
| ---- | -------------------------------------------------------- |
| 空   | 按场景说明原因与下一步动作                               |
| 加载 | 提供可感知的忙碌状态；短请求按需延迟显示骨架屏，避免闪烁 |
| 错误 | 提供可操作的原因与适用的重试 / 恢复入口                  |

调用中按操作语义禁用重复提交，失败保留输入；提供取消的操作沿用实际取消语义。反馈位置与常驻错误见 [说明与布局稳定](#说明与布局稳定)。产品入口与空白首页见 [产品范围](../product-scope.md)。

## 交互反馈

- 可点击元素保留 hover 与 focus-visible 反馈。
- 按钮禁用使用 `disabled` 属性；表单错误就近关联字段，需要及时宣告时使用 `role="alert"`。
- HTTP(S) 外链复用 [`ExternalLink`](../../src/components/external-link.tsx)，由链接自身通过原生门面打开系统浏览器，保留链接地址、键盘和中键操作，失败时给出提示；浏览器预览保留标准新标签页行为。全局点击监听仅作为其他链接的兜底。

## 无障碍

资源树使用单一 Tab 入口与方向键导航，右键菜单支持 Shift+F10，拖放排序保留按钮替代；可调分隔条提供范围、当前值和方向键操作。

弹窗复用 `DialogContent` 的焦点记录与恢复；业务可用 `onCloseAutoFocus` 指定更合适的相邻项，非模态弹窗保留外部点击目标。触发项删除后沿用可聚焦祖先或主内容回退。关闭按钮消费当前语言；设置搜索取消回到搜索框，选中后保留目标项焦点。

- 图标按钮有可访问名称，键盘焦点清晰可见。
- 状态除颜色外还有文字或图形标识。
- 弹窗与菜单支持键盘操作和 Esc 关闭。
- 内容图片有替代文本，装饰性图片使用 `alt=""`。

## 明暗主题检查

按改动检查边框、图标、插图、阴影和控件状态；正文对比度达到 4.5:1，部分选择、禁用与校验状态可辨识。共享配色变化覆盖受影响的预设与自定义色，材质变化检查最终合成结果。

## 动效

动效对应明确操作，普通反馈短促并保持内容可读；遵循应用与系统减少动效偏好，强制颜色模式隐藏非必要光效。

- 持续动画通过 [useMotionActivity](../../src/hooks/use-motion-activity.ts) 观察呈现区域，取得包含应用偏好、系统减少动效、文档可见性和离屏状态的活动策略。
- 连续运动提供明确的暂停 / 继续入口。暂停、场景离屏或文档隐藏时冻结持续运动，恢复后从合理位置继续；卸载时停止播放并释放计时器、观察器、事件和指针捕获。
- 命令式循环和 SVG 绘制显式启动、暂停和停止；CSS 动画按活动状态切换 `animation-play-state`。
- 减少动效时直接呈现静态结果，输入、选择、布局切换、反馈和信息保持可用。
- 普通过渡优先使用 `transform` 与 `opacity`。控制粒子数、滤镜范围与逐帧更新成本，避免高频 React 状态更新驱动整页重绘。
- 侧栏折叠与主内容同步重排，沿用现有宽度与标签过渡，手动拖宽时直接跟随指针。
- 主窗口与次窗口共用主题 Hook，从各自主题按钮中心扩散，日月图标变换一致；首次恢复、隐藏窗口或减少动效时直接应用。
- 指针交互支持触屏、取消捕获和键盘替代；暂停、重播与图标按钮保留可访问名称。

## 代码展示

源码展示复用 `components/code-block.tsx` 并指定语言，未知语言用 `language="text"`；混合语言分块，普通文本和 URL 保持文本。

后缀与 Markdown 围栏识别共用 [语言归一化规则](../../src/lib/code-language.ts)。高亮适配明暗与强制颜色，保留空格、选择和复制；用户内容以 React 文本渲染，超出着色限额的文本完整保留。Markdown 预览更新保留现有表格和代码块的焦点与局部滚动位置；编辑输入优先更新，较重的预览可延后呈现并标明忙碌状态。
