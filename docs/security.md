# 安全规范

本文维护 IPC、系统服务、内容、更新与本地数据边界。检查按 [受影响行为](./testing.md#日常验证范围) 选择。桌面程序以当前用户运行，窗口与目录隔离不抵御同账户恶意进程；前端、配置和公钥均为公开内容。

## 攻击面

| 输入或资源        | 防线                                           |
| ----------------- | ---------------------------------------------- |
| WebView与外部内容 | CSP、安全渲染、受限原生能力                    |
| IPC和系统能力     | Rust提交边界、窗口身份、资源ID、最小capability |
| 本地存档          | 原子写入、revision、归档、格式校验与写入保护   |
| 运行和网络资源    | 有界阻塞池、预算、取消与生命周期               |
| 凭据和分发        | 受控 Secrets、TLS、版本绑定签名                |

## 能力最小化

[capabilities](../src-tauri/capabilities/) 管理 Tauri 核心与插件命令白名单，自定义 Rust 命令由各入口校验身份和数据。主 / 次窗口使用明确的能力配置，远程页面不获 Tauri 能力。

剪贴板、通知、自启动、窗口和外链通过门面与原生服务使用。文本导出路径由原生另存对话框授权，取消选择不写文件；Shell 命令与任意路径访问不向前端开放。

视频使用原生对话框授权和应用管理副本，媒体协议按窗口与内容 ID 复核。外部内容使用独立权限，新增能力说明用途、窗口范围与验证，并移除闲置声明。

测试WebDriver仅在可选测试feature和overlay中启用，正式配置不注册测试服务；隔离见 [真实桌面E2E](./testing.md#真实桌面-e2e)。

## CSP

生产规则读取 [tauri.conf.json](../src-tauri/tauri.conf.json)，浏览器预览规则读取 [vite.config.ts](../vite.config.ts)。新增来源按实际用途放行，并验证生产资源。

脚本只允许本地可信来源；内联样式支持控件浮层定位。图片使用同源资源、data / blob，视频使用受控媒体协议。关闭对象嵌入、基础URL改写、表单导航和外部嵌入。

CSP 变更后核对生产构建的启动、导航和对应资源，按被拦截的具体来源修正规则。Markdown 使用安全渲染，跳过原始 HTML 并过滤危险协议。

## 入参校验

前端输入和外部存档均不可信。类型生成提供编译期契约，Rust提交边界负责身份、格式、路径、额度与权限。校验对应实际失败和越权场景，命名与抽象规则见 [代码风格](./conventions/code-style.md#约束与复杂度)。

- 媒体以受控内容 ID 访问，导出路径由原生对话框选择，应用存档使用固定数据目录。检查路径组件、链接、特殊文件与打开后替换风险，字符串前缀不能建立目录边界。
- 设置使用 revision CAS 和原子替换，普通保存拒绝覆盖未来 schema，用户明确确认的设置重置可替换已读入的未来设置。图片 / 视频有体积和解码预算，视频仅暴露受控 ID 及固定 MIME，清理前核对真实引用。
- 原生工作通过有界队列执行，输入与输出使用明确预算。系统进程使用参数数组，用户文本不拼为 Shell 命令。
- 深链只导航当前允许的本地路由，不授权文件或设备。导出沿用显式用户选择与内容校验，不依赖文件后缀证明类型。

原生错误使用稳定code，内部细节只进脱敏日志；前端不解析错误文本。取消和等待超时不伪造已回滚，也不自动重放有副作用操作。

## 密钥与证书

构建签名、更新私钥和服务密钥通过受控环境或CI Secrets注入；运行时新增凭据能力时使用系统安全存储，普通 JSON 不存秘密。真实.env、私钥和口令不进入Git、日志或聊天。误提交后撤销或轮换，并评估已生成产物。

更新私钥离线备份，换钥通过可信过渡版本或手动安装完成。本机加密副本不能代替独立备份。公钥可提交，可信公钥不能从普通可写部署配置替换。

发布模板的 Action 固定到提交 SHA；停用目录通过手动审核更新。恢复前核对版本、SHA、参数与凭据作用域，见 [模板说明](../.github/workflows-disabled/README.md)。

## 依赖审计

```sh
pnpm audit
cargo audit --file src-tauri/Cargo.lock
```

自动配置范围读取 [audit.yml](../.github/workflows/audit.yml) 和 [dependabot.yml](../.github/dependabot.yml)。请求失败时记录审计未完成，结合完整输出处理告警。依赖审计由维护者手动触发，没有每周定时任务；实际审计结果在 PR 或里程碑验收中记录。

提交锁文件，新增依赖按 [评审标准](./development.md#新增依赖的评审标准) 审查。定向升级后检查依赖链、目标平台与许可，暂时无法修复的实际问题在PR说明原因和缓解。

## 更新通道

当前更新端点与公钥为空，框架停用且不联网。完整条件见 [自动更新](./build-release.md#自动更新)。

启用后端点须为无凭据、无fragment的HTTPS，原生拒绝HTTP降级，强制验证Tauri原生包签名和被签版本。`deployment.json`可覆盖镜像或以空端点禁用，但不能替换安装包内固定公钥。安装前重读策略，变化后重新检查；更新签名后的字节不得再修改。

公钥固定的原因见 [ADR 0020](./adr/0020-pin-updater-trust-root.md)。

## 本地数据

数据位置见 [数据存储](./architecture.md#数据存储)。设置、壁纸和日志未加密。新增秘密存储时单独定义系统存储与授权，测试不操作真实秘密。

设置和图库保持各自 schema 与写入边界，读取、迁移或备份失败保留原件。重置设置保留其他数据。

隔离恢复暂存默认设置候选，下次启动复核未来格式保护，归档正式设置原件后安装。失败回滚或保留日志与待处理证据；未知恢复元数据与原件保留，见 [恢复流程](./architecture.md#恢复诊断与更新)。

## 日志

日志不记录令牌、完整请求正文、用户私有内容或可避免的用户路径。生产默认不输出调试日志，诊断只读取有限近期日志并限速。复制或反馈前复核，基础脱敏器不能保证过滤所有业务数据，位置见 [先看日志](./troubleshooting.md#先看日志)。
