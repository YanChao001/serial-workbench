# 产品范围

Serial Workbench 提供 [M1 计划](./superpowers/plans/2026-11-07-m1-host-and-workspace.md) 的本机串口与工作区能力。桌面复用 starter 的外壳、主题和磨砂材质，以顶部连接、中央接收和底部常显发送组织串口工作台。独立 Rust Host 管理设备与操作，GUI、CLI 和官方 MCP SDK 共用目录、权限、状态和业务处理。软件验收范围与实际结果见 [后端记录](./superpowers/acceptance/2026-11-08-m1b-backend.md) 和 [工作台记录](./superpowers/acceptance/2026-11-08-m1b-workbench.md)。

## 独立 Host 与自动化入口

Host、CLI 与 MCP 可在没有桌面窗口时运行，构建和调用见[开发指南](./development.md#独立-hostcli-与-mcp)。设备后端包括系统串口、PTY 与 Virtual；收发保留原始字节、会话 epoch、配置 revision 和最终 TX 回执。各客户端使用独立认证身份，默认只有元数据权限；桌面明确选择设备或文件时，授权该目标所需能力，后续同目标操作复用授权。

CLI 使用显式上下文文件复用请求身份；MCP 工具由同一 Host 目录生成，长操作返回 Operation。关闭适配器不会停止 Host，取消等待与取消操作分别处理。系统串口和硬件线路的真实设备验证、实际 Codex 客户端交互及三平台长稳按后续阶段验收。

## 串口工作台

工作台提供文本与 HEX 接收、字节查找、暂停刷新与跟随、文本/HEX/混合发送预览、文件发送、串口参数和线路控制。RX/TX 字节及 I/O 错误在同一会话内跨重连累计，另显示本次连接时长和近一秒速率；输入线面板展开时每 500ms 采样，也可立即刷新，不支持的观测明确显示。

原始录制支持分卷、容量和空闲空间限制、验证、恢复前缀另存、文本导出及只读回放。加载工作区时，可将已保存的录制引用作为接收区的只读标签验证并查看尾部；不会自动连接设备或发送数据。大记录显示有界摘要，缺口、原始来源和未知 TX 结果保留，辅助资料就近展开。选中录制时仍可编辑本窗口的未连接草稿，与设备草稿分开，设备发送和控制保持禁用。

日常新建、关闭和调整标签只影响当前窗口；点击保存才把当前窗口布局与录制引用写入工作区模板，保存使用 revision 冲突检查。Host 不可用时保留本窗口草稿和工作区，显示中文错误与重试入口。设备最近连接在当前 Host 配置全局共享。

## 可见入口

| 入口             | 当前行为                                                         |
| ---------------- | ---------------------------------------------------------------- |
| 首页 `/`         | 串口工作台；设备、录制和工作区工具从附近入口展开。               |
| 设置 `/settings` | 侧栏左下角齿轮入口；语言、外观、窗口偏好、更新状态、诊断和恢复。 |

诊断恢复归入设置，启动故障时通过受保护的隔离页面进入恢复流程。页面、菜单和命令只提供当前可用操作。

## 公共框架

公共框架包括主/次窗口与生命周期管理、命令和快捷键、中英文、主题与皮肤壁纸、设置持久化和跨窗口同步、诊断恢复，以及构建和发布工具。桌面与浏览器共用 React 界面和 HashRouter；浏览器提供界面预览并使用独立存储，系统服务和安装更新需要桌面环境。

统一 Node 插件、浏览器连接和 LAN 属于后续里程碑，当前没有插件安装或执行入口。重构不提供旧软件 API、数据格式或插件迁入。默认设置恢复只操作其明确说明的数据范围。

## 自动化与发布状态

应用更新端点和验签公钥待配置；日常开发执行本机定向检查和无头界面验证，大节点里程碑手动运行 GitHub Actions 检查四目标；正式发布和 Pages 工作流仍为停用模板。启用更新、Pages 与自动发布时按 [构建与发布](./build-release.md) 配置和验收。
