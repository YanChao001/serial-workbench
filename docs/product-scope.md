# 产品范围

Serial Workbench 当前处于基础框架开发阶段，提供桌面界面、设置和插件宿主。串口连接、收发、录制与回放是后续业务方向。

## 可见入口

| 入口                   | 当前行为                                             |
| ---------------------- | ---------------------------------------------------- |
| 首页 `/`               | 空白工作区，作为后续产品功能的承载位置               |
| 插件中心 `/extensions` | 本地安装、授权、启停、卸载及已安装插件的受控入口     |
| 设置 `/settings`       | 侧栏左下角齿轮入口；语言、外观、窗口偏好、诊断和恢复 |

已安装插件可声明应用视图与独立窗口，由授权和插件生命周期控制。诊断与恢复归入设置，启动故障时通过隔离界面进入恢复流程。

## 公共框架

公共框架包括窗口与生命周期管理、命令和快捷键、中英文、主题与外观、设置持久化和跨窗口同步、诊断恢复、受控 Wasm 插件宿主，以及构建和发布工具。桌面与浏览器共用 React 界面；浏览器提供界面预览，原生插件执行、系统服务和安装更新在桌面环境运行。

插件由用户安装。市场当前收录为空，生产签名信任待配置；SDK 示例和测试 fixture 用于开发与契约验证。

## 自动化与发布状态

应用更新端点和验签公钥待配置；GitHub Actions 当前停用，日常开发执行本地检查。启用更新、Pages 与自动发布时按 [构建与发布](./build-release.md) 配置和验收。
