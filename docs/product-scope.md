# 产品范围

Serial Workbench 正按 [M1 计划](./superpowers/plans/2026-11-07-m1-host-and-workspace.md) 重构。桌面提供空白工作区、设置、诊断恢复和系统窗口能力；独立 Rust Host 提供 Virtual 设备、持久操作、本机 IPC、授权、状态投影和原始字节流，CLI 与官方 MCP SDK 共用 Host 的目录与业务处理。系统串口、PTY、录制回放、桌面工作区与 Node 插件体系继续开发。

## 独立 Host 与自动化入口

Host、CLI 与 MCP 可在没有桌面窗口时运行，构建和调用见[开发指南](./development.md#独立-hostcli-与-mcp)。当前后端为 Virtual；收发保留原始字节、会话 epoch、配置 revision 和最终 TX 回执。各客户端使用独立认证身份，默认只有元数据权限，授权与撤权通过明确的本地用户操作完成。

CLI 使用显式上下文文件复用请求身份；MCP 工具由同一 Host 目录生成，长操作返回 Operation。关闭适配器不会停止 Host，取消等待与取消操作分别处理。真实串口、硬件线路、实际 Codex 客户端交互和三平台长稳仍按各阶段验收。

## 可见入口

| 入口             | 当前行为                                                         |
| ---------------- | ---------------------------------------------------------------- |
| 首页 `/`         | 空白工作区，承载后续串口业务。                                   |
| 设置 `/settings` | 侧栏左下角齿轮入口；语言、外观、窗口偏好、更新状态、诊断和恢复。 |

诊断恢复归入设置，启动故障时通过受保护的隔离页面进入恢复流程。页面、菜单和命令只提供当前可用操作。

## 公共框架

公共框架包括主/次窗口与生命周期管理、命令和快捷键、中英文、主题与皮肤壁纸、设置持久化和跨窗口同步、诊断恢复，以及构建和发布工具。桌面与浏览器共用 React 界面和 HashRouter；浏览器提供界面预览并使用独立存储，系统服务和安装更新需要桌面环境。

当前不提供插件安装或执行入口，不加载旧包、旧授权和缓存。个人设置与现有用户内容保留；默认设置恢复只操作其明确说明的数据范围。

## 自动化与发布状态

应用更新端点和验签公钥待配置；日常开发执行本机定向检查和无头界面验证，大节点里程碑手动运行 GitHub Actions 检查四目标；正式发布和 Pages 工作流仍为停用模板。启用更新、Pages 与自动发布时按 [构建与发布](./build-release.md) 配置和验收。

新增业务按 [开发指南](./development.md#新增页面到-ipc-与测试) 接入路由、原生门面和测试。当前模块职责见 [架构说明](./architecture.md)，公共壳边界见 [ADR 0026](./adr/0026-independent-shell-boundary.md)。
