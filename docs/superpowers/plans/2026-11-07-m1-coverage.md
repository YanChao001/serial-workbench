# M1 功能覆盖与跨阶段切片

本表配套[实施计划](./2026-11-07-m1-host-and-workspace.md)，逐项对应[功能矩阵](../specs/2026-11-07-serial-workbench-feature-matrix.md)阶段列包含 M1 的编号。这里只定义任务落点；实际状态和证据仍写 `docs/superpowers/acceptance/feature-status.json`，不把规划表当验收结果。每项的查询/修改从同一Host目录与handler进入GUI/CLI/MCP；纯窗口呈现状态使用client目标能力，不另起业务实现。

M1 涉及 76 条跨阶段记录。账本的 `software` 状态覆盖该条目的全部软件范围，M1 切片进入候选后记为 `in-progress` 并链接 PR；含 M2—M6 后续切片的条目不能因 M1 检查通过就标为整项通过。M1 软件出口另见[后端验收记录](../acceptance/2026-11-08-m1b-backend.md)和[工作台验收记录](../acceptance/2026-11-08-m1b-workbench.md)，硬件与发行状态分别维护。

GUI 按用户后续确认的[工作台设计](../specs/2026-11-08-serial-workbench-gui-design.md)核验：保留 starter 导航的折叠与调宽，设备和辅助工具从就近入口展开；该设计替代原 Task12 的常驻第二设备侧栏和默认展开面板布局。
