## 修正方案

工作对象是持续读取和发送串口字节的工程工作台。默认视线顺序为设备与连接状态、数据、发送草稿；所有内容左对齐，字节列使用等宽字形。

配色继续使用语义 token 与现有主题选择，不向业务组件写入固定颜色。默认浅色方案的参考样本为纸白 `#FFFFFF`、正文墨色 `#202020`、边界灰 `#E5E5E5`、辅助灰 `#6B6B6B`、操作苔绿 `#4D7C0F`，深色基底参考石墨 `#171717`。主色用于可执行动作、明确选中和焦点；禁用动作使用中性材质。深色和用户自选强调色由现有主题模型提供。

界面继续使用 Geist 与系统中文回退，标题/控件/辅助文本建立有限的字号和字重层级；终端继续尊重用户字体，但补全等宽回退链。数据区与发送区共用终端排版，时间和字节范围保持可复制。
