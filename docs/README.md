# 工程文档

从 [项目首页](../README.md) 准备环境，再按任务读取以下文档。

| 文档                         | 维护内容                                 |
| ---------------------------- | ---------------------------------------- |
| [需求](./requirements.md)    | 产品目标、范围、247 项需求与验收意图     |
| [架构](./architecture.md)    | 当前模块、数据、安全、生命周期和关键取舍 |
| [开发规范](./conventions.md) | 代码、界面、权限、协作和文档约束         |
| [开发指南](./development.md) | 环境、接线、配置、构建、发布准备与排障   |
| [测试](./testing.md)         | 按改动选择检查、测试入口与验收要求       |
| [任务规划](./plan.md)        | M0—M6 路线、当前任务与完成条件           |
| [开发进度](./progress.md)    | 当前基线、未完成问题和有效验证结果       |
| [界面审查](./ui-review.md)   | 截图证据、界面问题、复现与修正范围       |
| [代码审查](./code-audit.md)  | 跨模块问题、交互性能证据与本轮验证边界   |

[需求状态账本](./feature-status.json)分别记录软件、硬件和发行状态。[契约目录](./contracts/README.md)维护 Host、流与操作、录制、Node 扩展和 runtime 分发要求；Rust DTO 与生成结果提供已实现的类型定义。

工程规则在所属文档维护一次，其余入口链接引用。实现变更同步对应指南；计划能力标明阶段，验收结果注明源范围。维护要求见[文档规范](./conventions.md#文档)。
