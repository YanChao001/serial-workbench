# 串口工作台界面设计

本页维护具体页面草稿、布局示例和 M0–M6 场景。先在[全局预规划](./ui-layout.md)按需求 ID 查入口、预留位置和相邻功能，再用本页细化实际任务。用户偏好、共享设计规则、先行草稿要求及历史证据见 [GUI 设计规范](./gui-design.md)。

新增或重排按[先设计后编码](./gui-design.md#先设计后编码)准备宽窄稿，使用真实中英标签、典型数据、空态及错误。实际截图随 PR 或验收留存，日常使用[无头浏览器](./testing.md#桌面边界)。

## 视觉语言

按连接、观察、操作组织。接收、解析和图表占主区。表单对齐，状态贴近动作，组内以间距分隔字段。

选用[共享控件、文字与材质](./gui-design.md#控件文字与材质)。主操作用 primary，次操作用 outline 或 ghost，危险确认用 destructive。标注单位、量程和错误的字段归属，宽表、波形与 HEX 在所属区域滚动。长路径、哈希与帧提供完整读取或复制入口。 [语义材质](../src/styles/surface-tokens.css)

## 应用标题栏草稿

宽窗左侧保留应用图标和文件、视图、帮助，右侧保留应用动作及平台窗口控件。窄窗将三组菜单放进同一个应用菜单，选项继续按原分组排列。浏览器还在同一行提供页面选择。长页面名称可省略显示，打开页面选择后能读到全名。左侧和右侧各自留出点击空间，标题栏保持单行。原生窗口的右侧控件与 macOS 左侧系统按钮保留系统行为及既有位置。

```text
宽窗  [图标] [文件] [视图] [帮助]   [可拖动区域]      [命令][主题][应用及窗口控件]
窄窗  [图标] [应用菜单] [浏览器页面选择 ▾]           [命令][主题][应用及窗口控件]
```

应用菜单支持方向键打开、查看和选择命令，短窗在菜单内部滚动。按 Esc 关闭后回到触发按钮。重新拉宽窗口恢复原分组入口。应用菜单跟随菜单栏偏好。沉浸模式仍可从边缘唤出原来的导航。设置中的窗口尺寸预设按内容宽度保持四列、两列或单列，侧栏调宽和大字体下保留完整标签。复验不同语言、字体尺寸、浏览器路由和原生窗口控件夹具，逐项确认控件可见、可点且未相互覆盖。

## 工作台与工具窗草稿

主界面延续固定连接栏、中央独立滚动和常显发送区。活动列表、协议说明、场景配置及统计按需进入侧栏或工具窗。

```text
宽窗的工作台
┌ 连接与会话 ──────────────────────────────────────────┐
│ 当前端口与状态                    工作台菜单  图表  任务 │
├ 会话列表 ──┬ 接收与协议结果 ─────────────┬ 可选详情 ────┤
│            │ 原始记录 / 解析 / 图表         │ 字段及来源    │
│            │ 中央内容独立滚动              │ 自身滚动      │
├────────────┴───────────────────────────────┴─────────────┤
│ 模式与发送配置    发送草稿                        发送  │
└──────────────────────────────────────────────────────────┘
```

工具窗用于完成一件事。短工具沿同一列显示输入和结果。复杂协议、测试和图表可以增加页签或分栏，顺序保持目标、输入、预览、结果和操作。页签后正文承担纵向滚动，紧邻正文的主操作可通过键盘到达。

### 大缓冲接收区草稿（DISP-15、PERF-06）

从原来的接收区阅读设备连续报文。宽窗保留接收工具和查找入口，接收列内对齐方向、记录号、内容与时间。窄窗复用接收工具的图标和溢出菜单，内容在同一列换行，字节定位和恢复跟随保持可达。

```text
宽窗  [接收] [显示选项] [搜索字节] [记录定位]
      │ ↓ 记录 600   packet-0600                      11:22:33 │
      │ ↓ 记录 601   packet-0601                      11:22:34 │
      [接收统计]                              [返回实时接收]

窄窗  [接收] [显示] [搜索] [定位]
      │ ↓ 记录 600   packet-0600 │
      │   11:22:33              │
      [返回实时接收]
```

最新记录继续跟随。向上阅读时保持正在看的位置，新到数据只更新原有待看提示。跳转按原事件和字节范围定位，即使目标在当前视口之外。搜索面板和定位面板沿用已有键盘入口，关闭后恢复触发按钮焦点。窗口宽度、字号及长行展开引起重排时，保留用户正在阅读的记录。空态、加载、源缺口、权限撤回和不可达位置沿用各入口的反馈，录制状态仍取 Host 的回执。

### Modbus 工作台入口与宽窄草稿

在工作台打开「协议分帧」。当前界面用独立工具区呈现 Modbus 能力。实时动作显示所绑定的会话和授权状态。离线报文的解码、比较和构造只更新工具结果，生成的字节可显式转入发送草稿。

| 工具区              | 主要输入与结果                                                                      |
| ------------------- | ----------------------------------------------------------------------------------- |
| Modbus 报文         | RTU、ASCII 或 TCP，按场景选择方向、路由及报文内容。预览校验、异常及原始字节。       |
| Modbus 主站时序     | 当前会话、请求参数、应答超时、迟到窗口和显式重试。结果保留各次 TX、RX、耗时与来源。 |
| Modbus 寄存器与监视 | 数据区、起始地址、长度和显示类型。逐项显示确认值，保持寄存器的写入入口单独呈现。    |
| Modbus 从站模拟     | 离线请求、地址模型和模拟结果。实时入口单列会话、应答延迟、启停和实际发送状态。      |

后续调整沿用下列宽窄草稿。控件使用同一工具窗字段刻度。校验靠近报文或字段，逐轮结果可以独立滚动。实时发送入口依照当前会话和权限可用，未接纳、运行、停止等待和终态均有自己的反馈。

```text
宽窗                                   窄窗
Modbus 主站时序 · 当前会话             Modbus 主站时序 · 当前会话
[传输方式 ▾] [TCP 路由 ▾]              [传输方式 ▾]
[请求报文                              [TCP 路由 ▾]
                                       [请求报文]
[应答超时] [迟到窗口] [重试次数]        [应答超时]
[执行事务]  [当前状态]                 [迟到窗口]
发送、应答、耗时、来源                  [重试次数]
                                       [执行事务] [当前状态]
                                       逐次结果与来源
```

验收核对宽窄、键盘焦点、切换封装时草稿归属，以及发送动作的会话、授权和真实回执。自动回归在 [framing-tool.spec.ts](../e2e/browser/framing-tool.spec.ts)，独立对端步骤见[主站事务专项](./acceptance.md#modbus-主站事务参考动作proto-09proto-17proto-20)。

按实际可用的容器宽度变换字段列数。窄工具窗把字段和标签从左右排列改为上下排列，保留正文及键盘操作。结果表格、命令编辑和长帧在所属面板内展开。图表优先保留坐标标签、数值和筛选状态，侧边的来源及导出可下移到同一滚动区。

### 双会话拆屏草稿（DISP-17）

从工作台更多工具打开「双会话对比」。在同一窗口选两个已经打开的会话，比较留存中的真实 RX。每端保留自己的时间、事件号、起始偏移和可选择的 HEX。宽窗等宽并排，短窄窗上下排列，每端仍有独立的可聚焦滚动区。使用窗口现有的字号、控件高度、间距和阅读材质，留出显示完整会话名称和缺口的空间。

```text
宽窗                                         窄窗
┌ 双会话对比                        关闭 ┐   ┌ 双会话对比         关闭 ┐
│ [按时间 ▾]        [关闭联动]           │   │ [按时间 ▾] [关闭联动]  │
│ 同一源时钟内寻找邻近记录（±100 ms）     │   │ 按当前规则显示结果     │
│ [会话 A：COM3 ▾]  [会话 B：COM14 ▾]    │   │ [会话 A：COM3 ▾]       │
│ ┌ 事件、偏移与 HEX ┐ ┌ 事件、偏移与 HEX ┐│   │ 记录与 HEX 独立滚动     │
│ │ 本侧独立滚动     │ │ 本侧独立滚动     ││   │ [会话 B：COM14 ▾]      │
│ └──────────────────┘ └─────────────────┘│   │ 记录与 HEX 独立滚动     │
└─────────────────────────────────────────┘   └────────────────────────┘
```

滚动任一端时，按其可见的首条记录尝试定位对侧。时间模式限定同一来源时钟、无中断的区间及 ±100 ms，显示实际时间差。事件模式按相同数字的事件号，偏移模式按对端实际包含该 RX 字节偏移的范围。遇缺口、淘汰、无匹配、不可比时钟或撤权时保留对侧位置并提示，关闭联动后两端各自滚动。鼠标、触摸和键盘均可滚动，受控定位保持当前焦点。选中记录可查看本端完整 HEX 的分页，Esc 回到工具入口。

### 自动应答草稿（PROTO-14）

在现有「规则触发」工具窗中增加「载入自动应答示例」。宽窗沿用会话、规则 JSON、校验反馈、预览与操作栏。窄窗保持相同阅读顺序，操作按原控件高度换行。匹配 HEX 只使用已确认帧起点和完整长度。预览显示最终应答 HEX 与延时，旁边仍标观察时限。编辑器继续负责导出版本化模板和保留未保存草稿。

```text
宽窗                                    窄窗
目标会话 COM3                           目标会话 COM3
[规则 JSON 编辑器]                      [规则 JSON 编辑器]
条件 ＋ 效果 ＋ 观察时限                条件 ＋ 效果 ＋ 观察时限
应答 50 4F 4E 47 · 延时 250 ms          应答 50 4F 4E 47 · 延时 250 ms
[通知示例] [载入自动应答示例] [保存]     [通知示例] [载入自动应答示例]
[武装规则] [停止]                       [保存] [武装规则] [停止]
任务状态、匹配来源与写入回执            任务状态、匹配来源与写入回执
```

只在模板有效时预览应答。错误关联规则编辑器，载入示例和编辑保持原焦点。已有任务继续使用任务状态、取消和回执。显示匹配时说明可能仍处于延时或排队阶段，写入结果按真实 Host 回执呈现。

### 托盘规则提醒草稿（UX-07）

宽窗沿用规则触发面板。选择通知动作后，在动作摘要下方、武装按钮上方放置「托盘提醒」共用开关和同一行说明。使用现有状态区呈现正在观察的后台提醒及规则结果。桌面偏好的后台开关显示托盘可用性。

```text
规则触发                                   [关闭]

条件：文本匹配 · 动作：通知 · 观察 30 秒
```

窄窗保持相同的焦点顺序，让说明及状态自然换行，武装与停止沿用面板按钮换行。提示文字与正在观察状态均可通过键盘和读屏辨认。配对浏览器显示现有应用内通知。

### 示例工程草稿（UX-09）

复用会话模板下拉框和线路卡片。在 Arduino 采样、AT 模组和 Modbus RTU 读寄存器下显示「运行示例」区域。宽窗并排给出请求和预期应答，两者下方是模拟对端启动方式和保存按钮。Arduino 另提供固件源码。当前设备及「按模板打开」沿用原位置。模板名称为「Modbus 从站」时沿用从站工具。

```text
会话模板                             [关闭]
[Arduino 采样 ▾]          模板线路 115200 / 8N1
运行示例
请求 READ + CRLF          预期应答 3.250 + CRLF

[保存模拟对端] [保存 Arduino 源码]
```

窄窗的请求、应答和启动命令纵向排列。长 HEX 和命令可换行，按钮按自然宽度排列，焦点依序经过模板、打开和保存。正式连接和发送继续通过已有界面。

```text
[Modbus RTU 读寄存器 ▾]

运行示例

[保存模拟对端]
```

### TCP 连接草稿

从工作台的设备列表打开随包 TCP 传输。宽窗把地址和端口放在同一行，窄窗沿任务顺序换为单列。左边线和字段间距与其他工具一致。角色用共享下拉，输入和操作按钮沿用工作台控件高度。地址、端口用等宽字区分，提示与错误随内容换行，矮窗由弹窗正文滚动。

```text
宽窗  TCP 连接                                             ×
      角色      [TCP 服务端 ▾]
      本机地址  [127.0.0.1                 ]  端口 [43210 ]
      每个会话接纳一个对端。
                                               [开始侦听]

窄窗  TCP connection               ×
      Role           [TCP client ▾]
      Remote address [192.0.2.10  ]
      Port           [43210       ]
                         [Connect]
```

打开时聚焦角色，从地址到端口再到主操作。切换角色保留已填值，服务端显示本机地址及开始侦听，客户端显示远端地址及连接。空端口和超范围数值在对应字段下提示并聚焦。地址默认为 127.0.0.1。Host 接纳前禁用重复提交，在按钮原处显示连接或启动进度。失败保留输入并在按钮上方显示一次原因。日志沿用通知的事件去重，浮层留给当前窗外的状态。成功进入 Host 会话。服务端界面说明侦听启动后等待对端。关闭按共享草稿保护返回原入口。第三方及旧版参考包继续从已有 JSON 参数入口打开。

### UDP 连接草稿

从设备列表选择「UDP 数据报」，点现有连接按钮打开工具窗。选择地址族和模式，再填目标地址、端口和本机绑定。宽窗将地址与端口同行，两个端口列同宽。窄窗按同一顺序降为单列，标题和关闭入口留在工具窗，正文负责滚动。下拉、文本框、间距、字号与主按钮沿用 TCP 连接窗。地址及端口沿用等宽输入。

```text
1240×760 中文 · IPv4 组播
┌───────────────────────────────────────────────────────┐
│ UDP 数据报                                          × │
│ 地址族 [IPv4 ▾]             模式 [组播 ▾]              │
│ 组播地址 [239.255.15.42                 ]  端口 [42000] │
│ 组播接口 [192.0.2.10                    ]  本机端口 [      ] │
│ 请输入接口的本机 IPv4 地址。              默认使用目标端口。 │
│                                          [打开会话]   │
└───────────────────────────────────────────────────────┘

420×540 English · IPv6 unicast
┌───────────────────────────────────┐
│ UDP datagrams                   × │
│ Address family [IPv6 ▾]           │
│ Mode [Unicast ▾]                  │
│ Destination address [::1       ] │
│ Destination port [42000        ] │
│ Local address [                 ]│
│ Leave blank to use any local IP. │
│ Local port [                    ]│
│ Leave blank for an automatic port.
│                    [Open session]│

```

IPv6 的模式菜单提供单播和组播。IPv4 广播使用广播地址，定向广播需要对应本机接口地址。组播固定用通配地址接收，本机绑定区的地址字段改为组播接口。IPv4 填本机接口 IP，IPv6 填数字接口索引。字段下方说明接口格式和本机端口默认值，选项分别保留输入。字段校验定位首个错误，长错误完整换行。Host 拒绝后在主按钮上方显示连接失败及可检查的参数，并保留原值。只有实际成功的会话关闭窗口，关闭后回到连接入口或可继续操作的相邻控件。同步检查选择切换、待处理、失败重试、取消焦点和中英暗亮主题。UDP 会话打开表示本机套接字就绪，发送结果按本地接纳记录。

### WebSocket 设备连接草稿

从设备列表的「WebSocket 设备」进入现有连接窗。共享下拉选择主动连接或侦听，并指定发送文本或二进制。同一消息的类型和长度继续出现在 Raw 来源信息中。

```text
宽窗  WebSocket 设备                                               ×
      角色 [侦听                ▾]     发送类型 [二进制             ▾]
      本机地址 [127.0.0.1                        ] 端口 [          ]
      握手路径 [/device                                             ]
      浏览器来源 [http://localhost:5173                            ]
      浏览器的 Origin 必须与此值一致。                 [开始侦听]

窄窗  WebSocket device             ×
      Role [Connect               ▾]
      Send type [UTF-8 text       ▾]
      Endpoint URL
      [wss://device.example/data   ]
                             [Connect]
```

复用 TCP 和 UDP 的输入、按钮及对齐线。窄窗沿表单顺序降为单列，短窗滚动正文。切换角色保留各自的输入，非法地址、端口、路径及浏览器来源在对应字段就地提示。Host 拒绝时保留草稿，等待打开期间按钮保持位置并给出真实状态。侦听成功允许回到工作台等待对端，同一会话只接纳一次。关闭后按现有焦点规则返回连接入口。按中英宽窄窗核对控件高度、字段对齐、失败后重试和键盘焦点。

### RFC 2217 连接草稿

### 命令库和会话对比草稿

命令库宽窗让分组和命令列表并排，选项按内容可用宽度分列，换到下一行的单个下拉占满该行，长选项保留完整文字。窄窗时分组在前，命令列表和编辑字段沿纵向排列，编辑时保存操作贴在可滚动区域底端。模式、编码和行尾沿用共享下拉，使用键盘选择后返回触发位置。宽窗在固定操作栏左侧放撤销和重做，右侧放关闭、删除和保存。窄窗先显示历史操作，再显示保存等操作，字段滚动时为两行操作留出空间。撤销导致自定义行尾字段消失时，焦点回到行尾下拉。长变量名和备注明确换行，移动、分页、保存和加载发送草稿保留各自的反馈。命令正文标题旁显示可拖放范围和载入按钮。文件预览放在正文上方，显示文件名、大小、开头字节和本次会发生的替换。取消导入回到载入按钮，确认后聚焦正文。撤销恢复替换前的内容和发送格式。

回放栏按接收区的实际宽度排列。窄窗时播放、跳转和更多操作可以分行，完整状态另起一行。按键顺序和读取、暂停、单步语义保持一致。会话对比宽窗并排显示基准与对照，窄窗按相同顺序上下排列。对齐方式、匹配字段和定义在结果之前。结果表过宽时在表格区域内横滚，焦点可进入该区。当前行的原始帧和字段详情放在表后，保留空项、范围与权限变化提示。关闭对比后回到原入口。

Windows 卸载的附加清理范围是当前用户配置、缓存及对应安装偏好。更新和无交互卸载按既有行为保留用户数据。取消后核对原安装与用户文件。使用隔离账户测试保留和明确清理两条路径，验证中英、系统字体、100%/150%/200% 缩放、长路径、键盘焦点、断网安装和首次打开。使用安装器实际结果核对应用和用户文件去向。

macOS 保留系统的 DMG 挂载、复制应用和安全确认流程，记录复制、启动和更新结果。Linux 保留软件中心或发行版包管理器的依赖、进度和失败说明。两者均在各自平台记录依赖缺失、离线和卸载后用户文件的保留情况。

## M0–M6 审查范围

从 M0 基座到 M6 安装和发行，覆盖所有用户可见的页面、弹层和流程。以主线和各候选的实际功能为依据，`cb394e9`（#52）用于追踪 M2 前后的变化。每组在中英、明暗和宽窄窗口下走代表性任务，记录对应变更和复验。尚未交付的界面先定稿和明确验收。系统原生安装器、文件选择器和权限提示沿用平台控件，应用负责清楚说明下一步并正确接回状态。
