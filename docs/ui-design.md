# 串口工作台界面设计

新增界面或重排现有界面时，先完成宽窄两版草稿，再编写界面代码。草稿随 PR 说明一起审查，标明真实入口、主要任务、控件、对齐、滚动、操作顺序及状态变化。用实际中英标签、代表性设备数据、空态和错误举例。还原后的截图与草稿一起保留在 PR 或验收产物中。日常复验使用[无头浏览器](./testing.md#桌面边界)。

## 视觉语言

工作台按连接、观察、操作组织信息。接收数据、解析结果和图表使用主要空间。工具表单沿同一条左边线对齐，状态紧靠会受影响的行为。把分组边框留给需要独立阅读或操作的区域，同一组内用间距区分字段。

| 要素       | 设计约定                                                                                                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 色彩与材质 | 整体跟随当前皮肤和[语义材质](../src/styles/surface-tokens.css)。主操作用 primary，次操作用 outline 或 ghost，危险确认用 destructive。输入用 control、长文本用 reading、关键错误用 solid、图表用 artwork。 |
| 字体       | 标题、正文、标签与按钮沿用应用的字体和字重。字节、原始偏移、精确数值及代码使用等宽字，统计列使用等宽数字。层级由大小和字重建立，技术标识可以展开或复制。                                                  |
| 尺寸       | 同一表单内输入、下拉、文件选取和同行按钮沿用同一控件高度。工具栏、表单和设置页分别沿用所属的共享尺寸。图标按钮以现有共享控件为准，保留可访问名称和按键焦点。                                              |
| 间距与对齐 | 用共同的字段间距、分组间距与内容边距。并列字段按同一栅格起点排列，标签换行后仍与相邻输入对齐。行内的单位、量程和错误归属同一字段。                                                                        |
| 换行       | 普通说明、状态和错误按词自然换行。长路径、哈希、帧和导出文件名保留完整可读取或可复制的值。宽表、波形与 HEX 在自己的区域滚动。                                                                             |
| 交互       | 先给用户看目标和范围，再给可预测的主操作。一个任务区突出当前一步，相关次操作相邻排列。当操作已提交时，在原位置展示接受、运行、停止请求或终态。弹窗关闭后沿用焦点返回和未保存工作协商。                    |

## 应用标题栏草稿

宽窗左侧保留应用图标和文件、视图、帮助，右侧保留应用动作及平台窗口控件。窄窗将三组菜单放进同一个应用菜单，选项继续按原分组排列。浏览器还在同一行提供页面选择。长页面名称可省略显示，打开页面选择后能读到全名。左侧和右侧各自留出点击空间，标题栏保持单行。原生窗口的右侧控件与 macOS 左侧系统按钮保留系统行为及既有位置。

```text
宽窗  [图标] [文件] [视图] [帮助]   [可拖动区域]      [命令][主题][应用及窗口控件]
窄窗  [图标] [应用菜单] [浏览器页面选择 ▾]           [命令][主题][应用及窗口控件]
```

应用菜单支持方向键打开、查看和选择命令，短窗在菜单内部滚动。按 Esc 关闭后回到触发按钮。重新拉宽窗口恢复原分组入口。应用菜单跟随菜单栏偏好。沉浸模式仍可从边缘唤出原来的导航。设置中的窗口尺寸预设按内容宽度保持四列、两列或单列，侧栏调宽和大字体下保留完整标签。复验不同语言、字体尺寸、浏览器路由和原生窗口控件夹具，逐项确认控件可见、可点且未相互覆盖。

## 工作台与工具窗草稿

主界面延续固定连接栏、中央独立滚动和常显发送区。活动列表、协议说明、场景配置及统计按需进入侧栏或工具窗。

```text
宽窗的工作台
┌ 连接与会话 ──────────────────────────────────────────┐
│ 当前端口与状态                    工作台菜单  图表  任务 │
├ 会话列表 ──┬ 接收与协议结果 ─────────────┬ 可选详情 ────┤
│            │ 原始记录 / 解析 / 图表         │ 字段及来源    │
│            │ 中央内容独立滚动              │ 自身滚动      │
├────────────┴───────────────────────────────┴─────────────┤
│ 模式与发送配置    发送草稿                        发送  │
└──────────────────────────────────────────────────────────┘
```

工具窗用于完成一件事。短工具沿同一列显示输入和结果。复杂协议、测试和图表可以增加页签或分栏，顺序保持目标、输入、预览、结果和操作。页签后正文承担纵向滚动，紧邻正文的主操作可通过键盘到达。

```text
宽工具窗                               窄工具窗
┌ Modbus 主站                关闭 ┐      ┌ Modbus 主站       关闭 ┐
│ 会话 COM3                  就绪 │      │ 会话 COM3         就绪 │
│ [请求] [响应] [监视]            │      │ [请求] [响应] [监视]   │
│ 传输方式       [RTU          ▾] │      │ 传输方式              │
│ 单元地址       [1              ] │      │ [RTU                ▾] │
│ 起始寄存器     [0              ] │      │ 单元地址              │
│ 预览           01 03 00 00 …   │      │ [1                    ] │
│ 请求状态或结果                   │      │ 预览与结果            │
│                     [发送请求]  │      │            [发送请求] │
└─────────────────────────────────┘      └───────────────────────┘
```

按实际可用的容器宽度变换字段列数。窄工具窗把字段和标签从左右排列改为上下排列，保留正文及键盘操作。结果表格、命令编辑和长帧在所属面板内展开。图表优先保留坐标标签、数值和筛选状态，侧边的来源及导出可下移到同一滚动区。

### 命令库和会话对比草稿

命令库宽窗让分组和命令列表并排，选项按内容可用宽度分列，换到下一行的单个下拉占满该行，长选项保留完整文字。窄窗时分组在前，命令列表和编辑字段沿纵向排列，编辑时保存操作贴在可滚动区域底端。模式、编码和行尾沿用共享下拉，使用键盘选择后返回触发位置。宽窗在固定操作栏左侧放撤销和重做，右侧放关闭、删除和保存。窄窗先显示历史操作，再显示保存等操作，字段滚动时为两行操作留出空间。撤销导致自定义行尾字段消失时，焦点回到行尾下拉。长变量名和备注明确换行，移动、分页、保存和加载发送草稿保留各自的反馈。命令正文标题旁显示可拖放范围和载入按钮。文件预览放在正文上方，显示文件名、大小、开头字节和本次会发生的替换。取消导入回到载入按钮，确认后聚焦正文。撤销恢复替换前的内容和发送格式。

回放栏按接收区的实际宽度排列。窄窗时播放、跳转和更多操作可以分行，完整状态另起一行。按键顺序和读取、暂停、单步语义保持一致。会话对比宽窗并排显示基准与对照，窄窗按相同顺序上下排列。对齐方式、匹配字段和定义在结果之前。结果表过宽时在表格区域内横滚，焦点可进入该区。当前行的原始帧和字段详情放在表后，保留空项、范围与权限变化提示。关闭对比后回到原入口。

```text
命令库宽窗                    会话对比窄窗
[导入][导出]                  [基准和原始范围]
[分组]     [所选分组的命令]   [对照和原始范围]
[分页]     [移动  分页]       [对齐方式  匹配参数]
[命令正文  模式/编码/行尾]    [对比] [结果横向滚动]
[撤销][重做]  [关闭][保存]   [基准帧] [对照帧]
```

分别在宽、窄窗口验证保存自定义行尾、切换编码、命令分页和会话对比。检查同一行的控件高度、页内宽度、键盘选择和焦点返回，并用长备注或长采集标识复查分组与证据排版。

### 录制、任务和证据草稿

录制工具宽窗使用统一的标签和字段轨道。窄窗把标签放到控件上方。录制目标、回放来源、恢复目标和导出目标都沿用同一文件控件。空态显示操作提示。选择文件后，焦点回到浏览按钮，文件名可通过键盘移动光标、选择和复制。文件控件与同组下拉同高。校验预览按标签和值呈现，证据仍在详情中读取。

```text
宽录制工具                               窄任务窗
[录制] [回放] [高级]                    录制会话               [详情]
目标文件  [设备采集记录.swbc] [浏览]     正在录制
写入方式  [新建               ▾]       已写入                 512 条
                             [开始录制]  [停止录制]
                                       正在等待录制停止
```

任务列表宽窗在同一行显示任务名、状态和详情。窄窗将任务状态放到名称下方，详情仍与名称对齐。进度和证据放在所属任务下。停止请求的反馈紧跟停止操作，录制、等待停止和正式终态各显示自己的文案。复验长文件名、窄而矮的窗体、详情焦点返回、导出与录制主动作，以及停止请求和终态的区别。

## 分析、设置和扩展草稿

宽界面让图表或当前配置占主列，详情和次操作在右栏。实际容器太窄时，主列按目标、数据和反馈顺序完整展开，详情下移。设置的标题和说明先行，开关、选项、保存状态和错误相邻。扩展安装或启用前显示来源和权限，在同一位置展示当前步骤的结果。

```text
宽分析区                            窄分析区
┌ 数据源   范围   筛选 ─────────┐   ┌ 数据源、范围、筛选 ┐
│ 图表或表格      │ 来源和统计  │   │ 图表或表格          │
│ 坐标与选中值    │ 输入与版本  │   │ 来源和统计          │
│ 导出与反馈      │             │   │ 导出与反馈          │
└─────────────────────────────┘   └────────────────────┘
```

### M5 专业分析草稿

从已启用且受信的统计扩展详情进入。先看到带说明的输入与示例，计算后依次显示采样范围和参数、图表及可检查的结果。宽布局按结果容器的宽度切为两栏。窄布局按相同顺序纵排，长时钟标识、采样区间和单位在所属区域换行。

```text
宽频谱结果                        窄频谱结果
采样率、观测与缺样、窗参数        采样率、观测与缺样
瀑布图、频率范围  │ 直方图         窗参数、瀑布图与频率范围
[时间窗口 ▾]     │ [范围 / 数量]  [时间窗口 ▾] 状态
频谱、频点或主峰  │                频谱、频点或主峰
                                 直方图

跨源 XY 宽窗                     跨源 XY 窄窗
连线 / 散点与坐标 │ 时钟与来源    连线 / 散点与坐标
                  │ 样本序号     样本序号、时钟与来源
```

频谱的时间窗口和频点复用应用下拉。选择自动主峰后仍标明自动模式，旁边显示当前窗口实际读数。缺样状态留在同一窗口区。直方图复用共享表格，数字对齐，保留缺样和箱外计数语义。跨源 XY 的图表及逐点证据按同一布局规则排列，保留选点、连线切换和已验证的来源。分别验证典型样本、长标识、缺样窗口、错误与键盘选择。

### 插件视图草稿

从扩展详情或工作台打开独立插件视图。打开前在入口说明目标会话。浏览器弹窗的宽版把插件名称、语言和关闭放在同一行。窄版把名称放到第一行，语言和关闭右对齐放到第二行。发布者提供的长标题自然换行，控件沿用共享下拉和图标按钮尺寸。

```text
浏览器宽窗                                  浏览器窄窗
┌ 串口字段图表           [简体中文 ▾] [关闭] ┐  ┌ 串口字段图表与测量数据  ┐
│ 正在加载… 或插件数据                       │  │   [简体中文 ▾] [关闭] │
│ 插件数据在视图内滚动                       │  │ 正在加载… 或插件数据  │
└────────────────────────────────────────────┘  └──────────────────────┘
```

载入时在正文位置显示共享状态。准备完成后由插件内容接管正文区域。视图停止时在原处提示检查连接和重新打开。关闭后返回原入口。语言切换沿用工作台偏好，已打开的视图随之更新。独立桌面窗口保留系统窗口标题和关闭控件，加载与停止状态沿用当前语言和明暗模式。复验覆盖宽窄、矮窗、长标题、中英、键盘关闭和打开失败。

独立桌面的宽窄版均保留系统标题栏。等待期间将状态置于窗口正文中央。启动完成后由插件填满正文。停止后在同一位置说明原因和返回工作台重新打开的操作。长技术代码在窄窗内自然换行，状态跟随当前语言和明暗偏好。

```text
独立插件宽窗                                  独立插件窄窗
系统标题栏                         [关闭]    系统标题栏       [关闭]
                正在打开插件视图…                      正在打开…
或 视图已停止（原因） / 回到工作台           或 已停止 / 回到工作台
```

## 浏览器配对与写入接管草稿

桌面设置从「浏览器访问」进入。同一位置显示 Host 当前生效的权限，以及下一次配对的可选权限。生成后才在本次打开的对话框显示一次性配对码。共享输入和复制按钮同高，宽窗并排，窄窗顺序排列。短窗只滚动正文，打开浏览器或停用的操作在底部可达。关闭后焦点回到入口。仍在途的接纳继续按 Host 回执更新访问状态，旧对话框的配对码、复制反馈和局部错误随关闭结束。

```text
宽窗                                 窄窗
当前访问       只读                   当前访问  只读
下一次配对     [权限 ▾]               [权限 ▾]
配对码         [               ][复制] [配对码]
                                      [复制]
                    [停用][打开浏览器] [停用] [打开浏览器]
```

接管通知按标题、串口、原写入客户端、确认后果及动作的顺序显示。端口名或客户端标识过长时在对应值内换行，拒绝和确认沿用同高按钮。无法确认端口时解释原因并保留拒绝操作。提交后显示等待结果，失败留在通知里供重试。复验宽窗、窄短窗口、键盘焦点、配对和复制回执跨关闭隔离、状态停用及接管目标。

## 启动、恢复与发行草稿

启动、首次连接、更新和数据恢复沿用相同状态顺序。已保存的设置与工作区先显示当前可用状态，需用户决策的失败提供明确动作。原生安装器说明安装位置、离线依赖和数据保留选项，并以平台交互结束。

```text
未连接/首次启动                    恢复或更新
┌ 选择端口 ─────────────────┐       ┌ 数据恢复 ────────────────┐
│ Host / 串口当前状态         │       │ 当前状态和受影响范围       │
│ [端口]      [波特率]       │       │ 可保留的数据及下一步       │
│ 权限不足时就近提示          │       │ [展开详情]                │
│                    [连接] │       │ [返回]          [确认操作] │
└───────────────────────────┘       └───────────────────────────┘
```

M6 验收同时核对安装、断网首启、更新、失败恢复和卸载的界面顺序，以及便携目录不可写和换机凭据重建，记录系统、语言、缩放、实际候选与结果。涉及清理用户数据时，确认之前显示范围，完成后显示实际结果。

### 更新与恢复操作草稿

更新先显示当前版本及可用状态，再列出版本说明、检查、安装或重启。下载进度与状态相邻，操作按钮保留原标签，进度总量未知时显示已下载大小。宽窗状态与操作并排，窄窗从状态到操作纵向排列，按钮按实际空间换行。确认安装后键盘焦点到状态区，以便读到正在下载、安装及重启提示。

```text
宽更新区                               窄更新区
当前版本                              当前版本
下载中 34%       [版本说明][检查][安装] 下载中 34%
[进度]                                [进度]
                                     [版本说明][检查]
                                     [安装]
```

恢复先显示原件保留说明、可滚动的故障原因和归档标识，再给出安排恢复的操作。确认失败时在确认窗内说明原因并保留重试。安排成功后焦点到重启按钮，界面明确说明要到下一次启动才会尝试应用。复验长版本号、长路径、短窗、中英和键盘流程，分别记录真实安装器与界面夹具的结果。

### 诊断报告草稿

恢复区保留独立标题和跳转焦点。报告区先交代日志范围，再提供复制、保存和刷新。宽版把报告说明与操作并排，上缘对齐。窄版将操作下移，各按钮沿用共享小尺寸，文字保留并随可用空间换行。展开操作紧邻报告内容，键盘可从展开项进入代码区并滚动。JSON 保留原缩进，长值在预览内换行，预览高度随窗口限制。

```text
诊断宽窗                                      诊断窄窗
恢复状态及操作                                恢复状态及操作
报告预览             [复制] [保存] [刷新]     报告预览
日志范围与处理说明                            日志范围与处理说明
[展开诊断详情]                                [复制] [保存] [刷新]
有界 JSON 预览                                [展开诊断详情]
                                              有界 JSON 预览
```

初次读取期间显示读取状态，读取失败在报告区提供重试。已有报告时刷新失败，在同一区域提示并保留上一次成功的报告。保存取消后保留报告和当前焦点。复验窄窗、长技术字段、明暗、中英、键盘展开和滚动、刷新失败及取消保存。

### M6 系统安装与卸载草稿

Windows NSIS 保留系统向导的页眉、目录字段、按键顺序和确认按钮。清理数据仅在普通交互卸载的确认页提供，默认不勾选。复选框与系统安装目录的左边缘和宽度对齐，长文案可换行，控件字体和焦点沿用系统向导。

```text
英文 100% 缩放                         中文 150% 或更高缩放
卸载 Serial Workbench                 卸载 Serial Workbench
安装目录                               安装目录
[现有安装路径]                         [现有安装路径]
[ ] Also remove application data      [ ] 同时删除当前 Windows 用户的应用数据
    for this Windows user
                  [Cancel] [Uninstall]                      [取消] [卸载]
```

Windows 卸载的附加清理范围是当前用户配置、缓存及对应安装偏好。更新和无交互卸载按既有行为保留用户数据。取消后核对原安装与用户文件。使用隔离账户测试保留和明确清理两条路径，验证中英、系统字体、100%/150%/200% 缩放、长路径、键盘焦点、断网安装和首次打开。使用安装器实际结果核对应用和用户文件去向。

macOS 保留系统的 DMG 挂载、复制应用和安全确认流程，记录复制、启动和更新结果。Linux 保留软件中心或发行版包管理器的依赖、进度和失败说明。两者均在各自平台记录依赖缺失、离线和卸载后用户文件的保留情况。
