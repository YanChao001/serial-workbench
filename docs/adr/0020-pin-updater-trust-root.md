# 20. 将应用更新验签公钥固定在安装包内

- 状态：已采纳
- 适用范围：保留的应用更新框架
- 相关：[安全规范](../security.md)、[构建与发布](../build-release.md)

## 背景与取舍

部署配置选择镜像与开关，更新公钥决定哪些安装包可信。如果同一份用户可写配置能同时替换地址与公钥，配置污染就能改变更新信任。

## 决策

验签公钥只来自安装包内的编译期应用配置；可写部署配置只能复述相同值，不匹配时拒绝更新。切换镜像与禁用更新不改变信任根。换钥通过可信安装包和可验证过渡完成。

当前启用条件与配置状态见 [自动更新](../build-release.md#自动更新)。

## 影响与复查

首次启用与换钥需要可信分发，并分别完成签名和目标平台安装验证。若需要独立于应用版本的轮换，先设计密钥过渡协议。
