# 11. 通过能力宿主组合扩展贡献与受控效果

- 状态：已采纳
- 适用范围：插件宿主、授权、执行与私有数据
- 相关：[扩展指南](../extensions.md)、[安全规范](../security.md)、[升级授权](./0023-preserve-extension-upgrade-consent.md)

## 背景与取舍

插件需要执行计算、保存私有数据并请求系统服务。允许任意脚本访问宿主对象、IPC 或系统路径会扩大权限边界；仅增加固定业务白名单又让宿主混入具体插件逻辑。

## 决策

使用 Extism Wasm 运行时与类型化受控效果。清单声明命令、输入、结果、宿主兼容范围和必需 / 可选权限；原生提交边界核对安装身份、内容、授权和请求预算。插件按权限请求固定服务，不获得任意 IPC、Shell 或宿主对象。

执行与编译由受控 worker 承担，使用有界调度、取消和回收。私有存储按插件命名空间隔离，保留 revision 冲突、原子写入及损坏 / 未来格式保护。用户明确选择保存位置后才写出产物。取消不回滚外部已经完成的效果。

安装、来源校验与授权独立判断。插件中心管理用户明确安装的包，初始为空。

## 影响与复查

需要维护有限公共协议、版本兼容与服务生命周期。worker 执行分离不构成操作系统级权限沙箱。若改变运行时或信任模型，应重新设计包、权限、数据及回收边界。
