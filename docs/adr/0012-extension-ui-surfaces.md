# 12. 区分通用工具视图与插件自定义界面

- 状态：已采纳
- 适用范围：插件页面与独立窗口
- 相关：[扩展指南](../extensions.md)、[界面 SDK](../../sdk/README.md)

## 背景与取舍

宿主绘制的通用视图适合字段、表格和受控输出，但不能覆盖插件特有布局、Canvas 或复杂本地交互。持续扩充自定义组件树语言会增加宿主协议与维护成本。

## 决策

保留通用视图，并允许插件提供自包含 HTML / CSS / JavaScript 界面。自定义界面运行在隔离 iframe 中，通过固定 SDK 与受控桥调用获授权能力；不直接获得宿主 IPC 或文件路径。页面和独立窗口共用包、兼容及权限校验。

界面先完成主题和绘制握手再展示。插件负责本地交互状态，持久化、未保存工作及关闭协商按公共契约登记；卸载、撤权、页面离开和窗口销毁都回收对应资源。

## 影响与复查

宿主需要维护隔离、消息校验、焦点与生命周期，插件作者承担自定义内容的可读性与无障碍。若开放其他运行时或跨包通信，应先重新评估信任与版本边界。
