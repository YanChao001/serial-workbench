# 1. 采用 Tauri 2 作为桌面外壳

- 状态：已采纳
- 适用范围：Serial Workbench 桌面运行时
- 相关：[架构说明](../architecture.md)、[产品范围](../product-scope.md)

## 背景与取舍

应用需要现代 Web 界面、跨平台窗口和受控系统能力。采用系统 WebView 可以避免随应用分发完整浏览器运行时；代价是 Windows、macOS 和 Linux 的渲染、解码及系统集成存在差异，需要分别验证。

随包浏览器运行时能够统一更多渲染行为，但增加分发与资源成本；原生界面工具包则需要另一套界面技术和组件维护方式。

## 决策

采用 Tauri 2、Rust、React 19、TypeScript 与 Vite。界面和页面状态由前端负责，原生服务负责系统能力、持久化与边界校验。原生调用通过统一门面和由 Rust 生成的类型进入，权限按实际能力限定。

浏览器预览复用前端代码；原生插件执行、系统对话框及安装行为仍由桌面环境提供。

## 影响与复查

维护者需要同时维护 Web 与 Rust 代码，并验证目标 WebView。包体、启动时间与资源占用使用实际构建测量。若目标平台 WebView 无法满足产品功能，或运行时与团队成本显著变化，再评估技术栈。
