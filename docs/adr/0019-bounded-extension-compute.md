# 19. 按命令声明有界计算预算

- 状态：已采纳
- 适用范围：插件清单、Wasm 执行与离线验证
- 相关：[扩展指南](../extensions.md)、[预编译](./0017-precompile-enabled-extensions.md)

## 背景与取舍

部分插件需要更长但有界的计算。提高所有插件的默认预算会扩大无关模块的执行工作量；按插件身份特殊放行会让宿主混入业务。

## 决策

命令清单可选择固定预算档，省略时使用标准档。原生只采用已校验安装清单中的档位，前端、SDK 和效果请求不能传入任意 fuel 数字或无限预算。非法档位在清单与 worker 边界拒绝。

计算档只改变明确的计算额度，保留墙钟、内存、IO、排队、效果和取消预算，不增加系统权限。缓存按运行配置区分，预编译不创建实例。插件仍需限制自己的输入与状态规模。

## 影响与复查

更高计算预算会增加执行位的 CPU 占用，不同预算分别缓存编译结果也会增加缓存占用。预算耗尽或取消返回失败。持续触顶时先评估算法、分片与调度公平性，再复查固定档位。
