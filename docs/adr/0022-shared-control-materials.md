# 22. 让宿主与插件共用控件样式和材质规则

- 状态：已采纳
- 适用范围：应用与隔离插件的主题和标准控件
- 相关：[界面规范](../conventions/ui-guidelines.md)、[界面 SDK](../../sdk/README.md)

## 背景与取舍

宿主和 SDK 各自复制控件 CSS 容易遗漏新状态；只传颜色也不能保证背景、边框、尺寸和选中状态一致。注入整包应用 CSS 则会把宿主布局带入插件页面。

## 决策

宿主与 SDK 共用同一份 CSS：材质 token 与标准控件规则分别维护，主题快照传递完整文本。已注册 ShadowRoot 使用同一更新路径，插件作者可通过普通 CSS 定制。

阅读区域和控件使用成对语义色及必要底色，保持文字在壁纸上的可读性。Canvas、自绘内容和未注册 ShadowRoot 由作者保证对比度。共享 CSS 来自可信安装包，插件定制仅作用于自身界面。

## 影响与复查

共用规则减少重复维护，但不能替代界面的语义适配与可读性验证。若面向独立发布客户端开放组件协议，或共享样式来源不再可信，应重新设计版本与信任边界。
