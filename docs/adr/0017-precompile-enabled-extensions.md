# 17. 启用时预编译并保持独立执行实例

- 状态：已采纳
- 适用范围：插件启用、编译缓存与执行
- 相关：[扩展指南](../extensions.md)、[计算预算](./0019-bounded-extension-compute.md)

## 背景与取舍

首次运行时才编译会把冷启动成本留在用户动作中；复用已运行实例虽然可能更快，却会把可变状态带入后续调用。

## 决策

启用前只准备并缓存编译结果，不执行 Wasm start 或插件初始化。每次执行使用独立实例。缓存以模块内容及相关运行配置区分，受容量与时间预算约束；版本、内容或配置变化时失效。

预编译可取消，失败保留原启用状态。每次执行前校验安装身份与授权，缓存只复用编译结果。

## 影响与复查

编译成本前移到启用，缓存淘汰后仍有重新编译成本。若冷启动或内存成本超出实际需求，分别测量编译、实例化和执行阶段后再调整。
