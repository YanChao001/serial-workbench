# 16. 有界保留最近使用的插件界面

- 状态：已采纳
- 适用范围：插件页面切换与界面缓存
- 相关：[扩展指南](../extensions.md)、[自定义界面](./0012-extension-ui-surfaces.md)

## 背景与取舍

每次切换都重建插件界面会重复解析、握手并丢失局部状态；无限保留又会积累 DOM、内存和后台资源。

## 决策

按明确容量保留最近使用的界面。普通数据更新保持已有 iframe 和 DOM，身份、版本或安全条件变化时重建。文档按最近使用顺序淘汰，释放 iframe 与消息端口；会话字段和检查点保存在独立会话缓存，已登记的脏工作继续参与保存与退出协商。

隐藏界面停止可见性相关活动并拒绝新的不适用服务请求，在途结果按真实结算处理。需要长期保存的状态由插件通过持久化或检查点契约登记。

## 影响与复查

缓存提高切换连续性，局部未登记状态仍可能在淘汰时丢失。容量、内存或生命周期无法满足实际插件时，重新评估保留策略。
