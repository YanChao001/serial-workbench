# 23. 对授权范围未变的可信升级复用现有授权

- 状态：已采纳
- 适用范围：用户触发的插件升级
- 相关：[扩展指南](../extensions.md)、[安全规范](../security.md)

## 背景与取舍

没有新授权决定的升级重复弹出确认会打断操作；只按版本号或前端标签继承授权又无法准确识别来源和权限变化。

## 决策

只有用户触发、来源可信且一致、版本更高，且必需权限、可选权限、网络来源与方法集合完全相同的升级，才能继承原启用状态和授权。集合顺序变化不影响判断，已拒绝的可选能力保持拒绝。

首次安装、本地文件导入、来源或声明变化继续审阅。原生在安装提交边界决定能否继承授权，前端预判用于选择交互流程。冲突、校验或编译失败保留原安装，由用户重新发起操作。

## 影响与复查

需要保持前端提示与原生条件一致，并覆盖并发及安装回退。引入后台自动更新、动态权限或新信任来源时，重新评估授权方式。
