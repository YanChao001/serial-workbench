# 13. 用受控桌面服务支持插件

- 状态：已采纳
- 适用范围：插件请求的原生桌面服务
- 相关：[扩展指南](../extensions.md)、[安全规范](../security.md)

## 背景与取舍

插件需要部分系统能力，但浏览器界面和 Wasm 均不应直接持有任意系统句柄。为每个插件单独开放原生命令也会让权限和回收规则分散。

## 决策

桌面能力通过固定服务请求进入原生分派。每次请求校验插件身份、当前授权、参数、窗口归属和资源预算；用户文件选择及另存由系统对话框决定。长连接和媒体资源由原生服务持有，撤权、停用和窗口关闭触发回收。

服务协议只表达已实现的有限动作，不接受任意命令、路径或服务替换。服务授权与产品页面入口分别维护，通用服务可供已授权插件复用。

## 影响与复查

系统能力需要单独维护目标平台实现和失败语义。浏览器替身只能验证交互，无法证明系统效果成功。新增服务时重新确认授权、取消、输出上限、资源归属与稳定错误码。
