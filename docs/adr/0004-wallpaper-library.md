# 4. 将多图图库与当前背景设置分开保存

- 状态：已采纳；图片副本与背景快照的存储决定被 [0027](./0027-shared-host-and-node-extensions.md) 的 Host 引用体系取代
- 适用范围：设置中的图片图库与当前背景
- 相关：[架构说明](../architecture.md)、[视频壁纸](./0021-managed-video-wallpapers.md)

## 背景与取舍

把全部图片放进设置，会让每次偏好同步携带整套图库，并扩大设置快照。直接持久化用户原图路径又依赖原文件长期存在，增加路径授权与资源回收问题。

## 决策

图库与当前背景继续分离，避免偏好同步携带整套图库。M1 中，图库作为 ClientWindowState 的有界元数据保存 ObjectRef 与名称，当前背景由 Host SharedSettings 保存选中引用和显示方式；两者沿各自的 revision 与写入边界维护。媒体正文由 Host 读取时复核授权，引用本身不授予权限。

重置外观取消当前选择并保留图库；删除图库条目不修改用户原始文件或 Host 对象。晚到结果不能覆盖后续选择，临时播放票据随实例清理。损坏或未来格式拒绝覆盖，隔离恢复使用临时数据。旧图片快照、图库副本和浏览器 IndexedDB 图库不迁入新引用体系。

## 影响与复查

客户端元数据不拥有文件正文，原文件移动、变化或授权撤销会使媒体读取失败，保存的引用仍保留供用户处理。容量与格式只在当前架构与实现维护。需要原图管理、离线副本或跨设备同步时，重新评估 Host 文件归属与缩略图缓存。
