# 4. 将多图图库与当前背景设置分开保存

- 状态：已采纳
- 适用范围：设置中的图片图库与当前背景
- 相关：[架构说明](../architecture.md)、[视频壁纸](./0021-managed-video-wallpapers.md)

## 背景与取舍

把全部图片放进设置，会让每次偏好同步携带整套图库，并扩大设置快照。直接持久化用户原图路径又依赖原文件长期存在，增加路径授权与资源回收问题。

## 决策

图库独立持久化有界图片副本，当前背景仍保存可独立显示的图片快照。图库与设置分别进行版本校验、原子写入及跨窗口通知；内容 ID 用于去重，不作为授权依据。原生图库与浏览器预览使用各自的存储。

重置外观取消当前选择并保留图库；删除图库条目不修改用户原始文件。批量导入保留已成功项，晚到结果不能覆盖后续选择。损坏或未来格式拒绝覆盖，隔离恢复使用临时数据。

## 影响与复查

图库与当前图片存在受控重复，换取独立显示和恢复边界。容量、格式和迁移规则只在当前架构与实现维护。需要更大图库、原图管理或跨设备同步时，重新评估独立文件与缩略图缓存。
