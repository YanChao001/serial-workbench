# 15. 由插件实现图片供应商并复用受控媒体能力

- 状态：已采纳
- 适用范围：插件图片查询、媒体资源与壁纸设置
- 相关：[扩展指南](../extensions.md)、[安全规范](../security.md)

## 背景与取舍

图片供应商的接口、页面与查询方式会变化。将供应商业务写进宿主会使这些变化依赖应用重新发布；让网页直接处理任意媒体路径则扩大权限边界。

## 决策

图片供应商与查询逻辑由插件实现。宿主只提供经过授权的网络、图片校验、受控媒体资源和背景设置能力，限制来源、格式、像素、字节与缓存预算。外链打开和网络读取分别授权。

宿主校验技术格式与访问边界，不替图片供应商或插件证明内容许可。设置背景只提交已验证的资源；失败保留当前背景，不接受任意本机路径或远程视频引用。

## 影响与复查

插件承担供应商兼容和结果语义，宿主承担统一媒体与权限边界。需要新的媒体类型、供应商信任或分发机制时，先复查能力协议和资源生命周期。
