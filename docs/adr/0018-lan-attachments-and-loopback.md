# 18. 通过受控附件扩展局域网服务

- 状态：已采纳
- 适用范围：插件请求的局域网通信与附件
- 相关：[扩展指南](../extensions.md)、[安全规范](../security.md)

## 背景与取舍

局域网插件需要交换消息和附件，同时保持本机文件的选择权与保存位置由用户决定。让网页或远端节点指定路径会扩大文件访问权限。

## 决策

连接、协议和有界附件缓存由原生服务持有。发送文件由系统选择器授权，保存位置由另存对话框决定；附件校验大小、格式及内容完整性，拒绝远端路径和自动执行。停止、撤权、窗口关闭及插件停用回收所属资源。

局域网明文服务只适用于用户信任的网络。节点自报身份和内容哈希不构成远端认证。缺少确认不等于没有发送，不能自动重放产生重复副作用。

## 影响与复查

宿主需要维护传输、附件缓存和资源回收，插件负责消息交互。需要加密、远端认证、中继、断点续传或后台常驻时，重新设计协议、密钥、任务与资源归属。连接验证范围见 [测试规范](../testing.md)。
