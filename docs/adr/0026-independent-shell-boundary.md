# 26. 保留公共桌面壳并移除未承接的业务入口

- 状态：已采纳
- 日期：2026-11-06；2026-11-07 按重构清理后的实现收敛
- 相关：[产品范围](../product-scope.md)、[架构说明](../architecture.md)、[测试规范](../testing.md)

## 背景与取舍

产品需要从可验证的基础继续建设。只隐藏旧业务导航仍会留下可调用路由、原生命令、依赖和打包内容，增加权限、生命周期和验证成本，并让界面暗示尚未交付的能力。

## 决策

当前保留空白工作区和设置入口，诊断恢复归入设置，启动隔离保留受保护页面。窗口、主题、中英文、皮肤壁纸、设置同步、诊断与更新框架继续承担公共职责。

删除未承接的业务页面及其专属源码、路由、命令、文案、资源、依赖、测试和教程。重构不为旧插件软件建立兼容层，当前无插件安装或执行入口。后续串口和插件业务在具备实际实现后再接入。

个人设置、图库和用户内容保留各自数据归属。设置维持原子写入、revision、未来格式保护与恢复证据；源码清理不自动清除用户目录。浏览器继续使用 HashRouter，原生门面检查运行环境。

## 影响与复查

源码、生成绑定、权限、依赖、安装资源与当前指南必须与实际能力一致。验收检查工作区、设置与隔离恢复，并核对已删除业务没有路由或命令入口。新增业务时定义功能、状态、权限和失败语义，更新产品范围与所属指南。
