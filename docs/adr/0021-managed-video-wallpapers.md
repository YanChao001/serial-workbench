# 21. 用独立媒体副本保存视频壁纸

- 状态：已采纳
- 适用范围：设置中的本机视频壁纸
- 相关：[图片图库](./0004-wallpaper-library.md)、[架构说明](../architecture.md)

## 背景与取舍

把视频字节放进设置会扩大每次同步；只保存用户文件路径又依赖原文件长期存在。因此视频需要独立的资源归属。

## 决策

系统对话框选中的视频经校验后复制到应用管理目录，以内容引用定位；设置和图库只保存有界封面与引用。播放通过受控协议提供有界字节范围，不开放任意路径。浏览器预览独立保存 Blob，并创建、释放临时 object URL。

播放静音循环，按界面活动状态暂停并释放资源；资源缺失或解码失败显示保存的封面。媒体清理保护当前设置、其他窗口与近期导入的引用，存档损坏或格式未知时保留副本；隔离恢复使用临时数据。具体生命周期见 [架构说明](../architecture.md#数据存储)。

## 影响与复查

媒体与设置分开保存，设置归档不自动包含媒体副本。需要转码、跨设备同步或媒体随备份迁移时，重新评估资源归属与归档格式；目标平台的解码和长期播放仍需实际验证。
